# 写真・作品の保管

- 作成日: 2026-09-25
- 更新日: 2026-09-25

[個人情報のガイド](../docs/privacy.md)を読んでから保存します。実際のファイルは自分用のPrivateリポジトリにだけ追加してください。

画像の例: `YYYY-MM-DD-paper-bridge-01.jpg`。名前に本名や学校名を入れません。
作品記録から `../assets/ファイル名.jpg` のような相対リンクを付けます。

## 外部に置いた原本の所在メモ
- 対応する体験・作品:
- ファイルの説明:
- 保管先（保護者がわかるフォルダ名など）:
- 閲覧できる人:
- 最後に所在を確認した日:

パスワード・認証トークンは記入しません。動画や原本は外部保管先でもバックアップします。
