# PYPのUOIを参考にした、家庭の探究づくり

調査日: 2026-09-25

これはIBの公開資料を参考にした家庭向けの独自教材です。IB公式のプランナー・認定教材ではなく、学校のPYPのカリキュラム全体を置き換えるものでもありません。日本語の説明や問いかけは、この教材向けの言い換えです。

## 調べてわかったこと

PYP（Primary Years Programme）は教科の枠を越え、概念を通して理解を深める探究を重視します。学校が編成するProgramme of Inquiry（POI）は探究の全体計画で、Unit of Inquiry（UOI）はその中の一つの単元です。単発の実験や調べ学習を行うだけでなく、複数の経験を関連付けて理解を育てます。[1][2]

IBが公開する単元計画例では、central idea（中心となる考え）とlines of inquiry（探究の切り口）を関連付けています。家庭版でも、活動を先に詰め込まず「何を理解するための活動か」を考える手がかりとして採用します。[3]

### 6つの教科横断的テーマ

以下の日本語は本教材の説明用訳です。[1]

| IBのテーマ | 家庭で考える入口 |
| --- | --- |
| Who we are | 自分・人との関係・大切にしていること |
| Where we are in place and time | 場所・時間・歴史・移動 |
| How we express ourselves | ことば・絵・音・表現 |
| How the world works | 自然やものの仕組み |
| How we organize ourselves | 社会の仕組みや協力 |
| Sharing the planet | 資源・生き物・ともに暮らすこと |

家庭版では、テーマを一つ選ぶのも、体験の後から関連を見つけるのも自由です。毎年6テーマすべてを実施する課題にはしません。

## 家庭での組み立て方（本教材の提案）

以下は家庭で使いやすくするための手順例であり、IBが指定する固定の探究サイクルではありません。行ったり戻ったり、途中で問いを変えたりできます。

1. **出会う・今の考えを知る**: 実物、絵本、散歩などをきっかけに「知っていること」「気になること」を聞く。正解へ誘導しない。
2. **中心となる考えを仮置きする**: 単なる題名ではなく、ほかの場面にもつながる関係を一文で表す。これはおとなの設計メモであり、子どもが証明すべき結論ではない。
3. **切り口と本人の問いを分ける**: おとなが用意する探究の方向と、子どもが実際に発した疑問を分ける。家庭版では切り口を2〜3個ほどに絞ると扱いやすい。
4. **方法を選び、確かめる**: 観察・読書・聞き取り・実験・制作から本人が選ぶ。理科だけでなく、数える、説明する、人の立場を聞くなどを必要に応じてつなげる。
5. **途中でも見直す**: 絵、会話、作品、記録を見て「そう思う理由は？」と聞く。理解が変わったら残し、次の活動を調整する。
6. **共有・行動・振り返り**: 本人が選んだ相手に伝える、暮らしの中で工夫するなど。予定と実施を区別し、今は行動しない選択も尊重する。

子どもの主体性（agency）と、自分や周囲に働きかけるactionはPYPの重要な要素です。家庭版では、発表会や社会貢献を義務にせず、本人が選び直せる形にします。[2]

## 見方を変える問い

IBの個人探究支援資料にある概念を参考に、家庭での問いかけを作りました。すべてを使う必要はありません。[4]

| 概念 | 本教材の問いかけ例 |
| --- | --- |
| Form（形・特徴） | どんな特徴で分けられる？ |
| Function（働き） | どの部分が、何の役に立つ？ |
| Causation（原因） | 何が変わると、結果が変わる？ |
| Change（変化） | 前と今では、何が違う？ |
| Connection（つながり） | ほかのものと、どう関係する？ |
| Perspective（見方） | 別の人には、どう見えるだろう？ |
| Responsibility（責任） | 選ぶとき、誰や何への影響を考えたい？ |

## 学び方と、理解の証拠を残す

PYPはATL（Approaches to Learning）として、思考、コミュニケーション、リサーチ、自己管理、社会性に関わるスキルを扱い、学習に組み込んだ評価を重視しています。[5]

家庭版では「二つの資料を比べた」「相手の話を聞いて考え直した」など具体的な場面を残します。完成品の見栄えだけで判断せず、始め・途中・終わりの考えと根拠を比べます。点数や性格ラベルを付ける用紙にはしません。低学年なら口頭と絵だけでも十分です。
