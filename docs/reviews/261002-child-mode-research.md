理由: 当初は第三者の引用に依存し、13歳未満の実際の操作・対話を大人が担う条件を案内に反映できていなかったため。

- [公式のメモリ説明](https://help.openai.com/en/articles/8590148-memory-in-chatgpt)も再確認。会話を分けるだけではメモリを分離できないため、設定の確認へ修正した。

## 1. 調べたこと

### 1-1. ChatGPT の年齢条件（OpenAI 利用規約）

- 利用は13歳以上。18歳未満は保護者の許可が必要で、保護者が子どもの利用を許可した場合は規約が保護者にも適用され、保護者が子どもの利用に責任を負う。
- 年齢確認は自己申告が基本。
- 出典（openai.com は自動取得を拒否したため、規約を引用した第三者ページで確認）:
  - https://conductatlas.com/platform/openai/openai-terms-of-use/age-restriction-and-minors/
  - https://www.esparklearning.com/blog/can-students-use-chatgpt
- 結論: **小学生本人のアカウントは作れない。** 「本人モード」は保護者のアカウントで、保護者が同席して行う前提になる。13歳以上（中学生）になれば本人アカウント＋保護者機能に移行できる。

### 1-2. ChatGPT の保護者機能（Parental controls）

- 保護者と13〜17歳のティーンのアカウントを連携できる。保護者は、利用できない時間帯（quiet hours）の設定、音声モード・メモリ・画像生成のオフなどを管理できる。会話内容そのものは保護者も読めない。限られた安全上の場面でのみ通知が届く。
- 2026年1月から、アカウントの振る舞いから18歳未満と推定した場合に自動で保護を適用する「年齢推定」も導入。
- 出典: https://help.openai.com/en/articles/12315553-parental-controls-in-chatgpt （本文は自動取得不可。要約は https://www.wtvr.com/business/company-news/chatgpt-launches-parental-control-features-for-teen-users 等の報道と検索要約による）、年齢推定は https://openai.com/index/our-approach-to-age-prediction/ （同じく報道経由）
- 結論: 小学生には適用されない（13歳未満の連携は想定外）。**中学生版への移行時に使う機能**として覚えておく。

### 1-3. 文部科学省「初等中等教育段階における生成AIの利活用に関するガイドライン（Ver.2.0）」2024-12-26

PDF: https://www.mext.go.jp/content/20241226-mxt_shuukyo02-000030823_001.pdf （本文を抽出して確認）

- p.10: 「年齢制限や保護者の同意の必要性、生成物のライセンスの所在など、生成AIサービスの提供者が定める最新の利用規約を確認し、遵守する必要がある。」
- p.11（注15）: 「生成AIサービスの利用に当たっては、各サービスの提供者が定める利用規約に基づき、保護者の同意を取ることが必要となる場合がある。」
- p.17: 「小学校段階の児童が直接利活用することについては、発達の段階等を踏まえたより慎重な見極めが必要である。例えば、情報モラル教育やプログラミング教育の一環として教師による生成AIとの対話内容を数多く提示することなどを通じて基本的な事項を学んだり、生成AIに関する体験を積み重ねることで…」
- p.15: 個人情報を含むプロンプトを入力する場合、提供者が機械学習に利用するか否か等を十分に確認すべき。
- 結論: 学校向けの文書だが、家庭でも「小学生の直接利用は慎重に」「大人が対話を見せる段階から」「個人情報を入れない」という姿勢を踏襲するのが無難。教材側でも「本人モードは慣れてから、保護者同席、短時間」と位置づける。

### 1-5. 現在のリポジトリとの関係

- 既に「記録を作るときの質問」（4段階を1問ずつ）と「短く話しかけるだけで済むようにする」の既定動作がある。本人モードはこれを**子ども向けの言葉と役割**に切り替えるだけで作れる。
- 記録の「記録者」欄は「本人／保護者・代筆」なので、「本人（ChatGPTとの対話、保護者同席）」という書き方を足せばよい。
- 保存は従来どおり保護者が「この内容で保存してください」と言う。本人モードでも、子どもが保存を指示する設計にはしない。

## 2. 提案

### 2-1. 位置づけ

- 名前: **本人モード**（合図は「本人モードで」。終わりは「おわり」「保護者モードに戻って」）。
- 対象: 保護者モードで何件か記録を作って慣れた家庭。保護者のアカウントで、保護者が同席し、1回10分程度。低学年は音声モードか読み上げを使い、保護者が代わりに入力してもよい。
- 位置づけの文言（案）: 「ChatGPT が聞き役になり、子どもが自分の言葉で話した内容を、そのまま記録にします。答えを教える道具ではありません。」

### 2-2. 実装方法（推奨: A を基本、B を任意、D を保険）

1. **AGENTS.md に「本人モード」の節を追加**（A）。合図、話し方、役割、質問、禁止事項、終了と保存の流れを規定。
2. **docs/child-mode.md を新設**。保護者向けの説明（年齢条件、同席、メモリ設定、時間の目安）、本人モードの約束の全文、ChatGPT のプロジェクトに同じ文章を貼る手順（B）、AGENTS.md が読めていないときに貼るコピペ用プロンプト（D）。
3. **examples/prompts/06** として、本人モードの往復例（架空）を追加。保護者が「本人モードで」と送る→ChatGPT が子どもに話しかける→子どもが答える→「おわり」→記録案→保護者が確認して保存、まで。
4. templates/quick-note.md と experience.md の「記録者」の説明に「本人（ChatGPTとの対話、保護者同席）」を追記。
5. README の「使いたいものから選ぶ」か「子どもといっしょに」に1行、docs/ai-guide.md に短い節、.github/copilot-instructions.md に1行。

### 2-3. 本人モードのルール案（AGENTS.md に入れる内容）

- 合図: 保護者が「本人モードで」と送ったら開始。最初に「おうちの人はそばにいる？」と1回だけ確認し、「はい」で始める。保護者のアカウントで行うことを前提とし、子ども本人のアカウント作成を促さない。
- 話し方: 短い文、1回に1問、ひらがな多め（保護者が学年を伝えたらそれに合わせる。伝えなければ子どもの書き方に合わせる）。絵文字や過剰なほめ言葉は使わない。
- 役割: 聞き役。答えや正解を教えない。「おしえて」と言われたら「おうちの人といっしょにしらべてみる？」と返し、調べたいことを記録に残す。安全に関わることだけは例外として保護者に伝える。
- 質問の順番: 保護者モードと同じ4段階を子ども向けの言葉にする。
  1. 課題の設定: 「きょう、なにをみつけた？ なにがふしぎだった？」
  2. 情報の収集: 「どこで？ どんなふうに？ なにをためした？」
  3. 整理・分析: 「どうしてだとおもう？ まえとちがうところはある？」
  4. まとめ・表現: 「だれにはなしたい？ えにかく？ つぎはなにをしたい？」
  各1問まで、合計4問以内。「わからない」「いわない」はそのまま受け取り、次へ進む。
- 禁止: 名前・学校名・住所・友だちの名前を聞かない。子どもが言っても記録に入れない。評価（「すごい」「かしこい」）や性格の決めつけをしない。記録と関係ない雑談を続けない。
- 終了: 子どもか保護者が「おわり」と言ったら終了。本人の発言を「」のまま並べた記録案を、保護者モードの用紙で作る。記録者は「本人（ChatGPTとの対話、保護者同席）」、本人のことばは本人が実際に打った・話した言葉だけ。AI の質問文は記録に入れない（メモ欄に対話の要旨だけ残す）。
- 保存: 記録案を示したら保護者モードに戻り、保護者が確認して「この内容で保存してください」と言ったときだけ保存する。本人モード中は保存しない。
- 時間: 開始から10分を目安に「ここまでにする？」と1回聞く。

### 2-4. 保護者向けの注意（docs/child-mode.md に書く内容）

- 13歳未満の本人アカウントは作れない。保護者のアカウントで、保護者が同席する。規約上、利用の責任は保護者にある。
- 文科省ガイドライン（Ver.2.0, p.17）は小学生の直接利用に「より慎重な見極め」を求めている。本教材でも、保護者モードで対話を見せる段階を経てから、短時間で試す。
- 設定: メモリをオフにするか一時チャットを使う（子どもの発言が保護者のメモリに残らないように）。モデル改善へのデータ利用をオフにする（docs/privacy.md）。
- 音声モード・読み上げを使う場合は、周囲に人がいない場所で、個人情報を話さない約束を先にする。
- 中学生になり本人のアカウントを持ったら、保護者機能（連携、利用時間、メモリ・音声のオフ）に切り替える。

### 2-5. 本人モード開始プロンプト（コピペ用の案・D）

```text
本人モードで。ここからは子ども本人が話します。おうちの人がそばにいます。
短い文で、1回に1つだけ質問してください。答えや正解は教えず、聞き役になってください。
名前・学校・住所は聞かないでください。「おわり」と言ったら、本人の言葉を「」のまま並べた記録の案を作り、おうちの人に確認を頼んでください。
```

## 3. 利用者の判断（2026-10-02）

1. 開始時の「おうちの人はそばにいる？」の確認は不要。
2. 保存は本人ができる形にし、「おわり」で自動保存する。
3. 低学年も音声で対象にする。
4. 保護者が代わりに入力する場合も本人モードに含める。
5. 子どもが「おしえて」と言ったら教える（記録では本人のことばと分ける）。
6. ChatGPTのプロジェクト用の指示文も用意する。
7. 例01〜05にも本人モードのやりとりを追記する。

これらは当初の提案（2-3）の一部を置き換える。確定したルールは AGENTS.md「本人モード」と docs/child-mode.md を参照。

## 3-旧. 当初に判断をお願いした点

1. 対象学年: まず4〜6年生から始めるか、低学年も音声で対象にするか。
2. 入力の担い手: 子どもが自分で打つ／話すのを基本にするか、保護者が代わりに打つのも「本人モード」に含めるか。
3. 「おしえて」への対応: 本人モードでは答えを教えない（提案）か、保護者が許可した場合だけ短く答える「しらべるモード」を別に作るか。
4. 実装の範囲: A（AGENTS.md）＋docs＋例06 だけで始めるか、B（プロジェクト用の指示文）まで用意するか。
