# GitHubって何？ 登録とログインのしかた

- 作成日: 2026-09-26
- 更新日: 2026-09-26

GitHub（ギットハブ）は、文章や画像などのファイルをインターネット上に保存し、**いつ、どこを書き直したかという履歴も残せるサービス**です。この教材では、子どもの体験や作品をためていく「家族の学びのノート置き場」として使います。

プログラミングの知識は不要です。まずはパソコンのブラウザーで登録し、用紙をコピーして文章を保存できれば大丈夫です。

## まず、この3つだけ

| ことば | この教材での意味 |
| --- | --- |
| アカウント | 自分用の登録情報。ログインして使うためのもの |
| リポジトリ | ノートや写真をまとめて保存する場所 |
| テンプレート | 自分用にコピーして使える、空欄の用紙のセット |

配布元のテンプレートは誰でも読める公開ページです。実際の記録は、そこから作る**自分用のPrivate（非公開）リポジトリ**に保存します。

GitHubの利用は原則13歳以上です。この教材では、**保護者自身のアカウントで、保護者が操作**します。子どもは話す・描く・体験する役割で参加できます。詳しくは[GitHubの利用規約](https://docs.github.com/en/site-policy/github-terms/github-terms-of-service)をご確認ください。

## どこから始める？

- **Googleアカウントを持っていない** → 下の「1」から。
- **Googleアカウントを持っているが、GitHubは初めて** → 「2」から。
- **GoogleでGitHubに登録済み** → 「3」から。
- **以前からGitHubを使っている** → いつもの方法でログインし、「4」へ。Googleログインに変えたい場合は末尾の説明を参照してください。

GoogleとGitHubは別のサービスです。「Googleでログイン」は、Googleのアカウントで本人確認をしてGitHubに入る方法です。Googleアカウントを持っているだけでは、GitHubの登録はまだ完了していません。

## 1. Googleアカウントを作る

GmailやYouTubeなどにログインして使っている場合は、すでにGoogleアカウントを持っています。新しく作らず、保護者自身のアカウントを使えます。

持っていない場合は、次のように進みます。

1. [Googleのログインページ](https://accounts.google.com/)を開きます。
2. **「アカウントを作成」**を選び、用途は**「個人で使用」「自分用」などの個人向けの項目**を選びます。この手順では保護者のアカウントを作ります。
3. 名前・生年月日など、画面で求められる情報を入力します。
4. 新しいGmailアドレスを選ぶか、作成します。すでにメールアドレスがあり、それを使いたい場合は、**「既存のメールアドレスを使用する」**を選べます。
5. パスワードを設定し、メールや電話による確認を求められたら、画面の案内に従います。既存のメールを使う場合は、その受信箱に届いた確認コードを入力します。
6. 表示される利用規約・プライバシーの説明を確認し、同意できる場合に登録を完了します。

再設定用のメールアドレスなども設定しておくと、ログインできなくなったときの復旧に役立ちます。画面の順番や表記は端末によって異なります。[Google公式の登録手順](https://support.google.com/accounts/answer/27441?hl=ja)

## 2. GoogleアカウントでGitHubに新規登録する

1. [GitHubの新規登録ページ](https://github.com/signup)を開きます。**Sign up**は「新規登録」という意味です。
2. **Continue with Google（Googleで続ける）**を押します。
3. 保護者のGoogleアカウントを選びます。候補になければ「別のアカウントを使用」などを選び、Google側でログインします。
4. GitHubに提供される情報などの確認画面が出たら、内容を確認して進みます。
5. GitHubに戻り、画面に従って**Username（ユーザー名）**などを設定します。ユーザー名はプロフィールのURLなどに使われるため、子どもの本名・学校名を含まないものにします。
6. 利用規約等を確認し、登録を完了します。メール確認や人による操作の確認が表示された場合は、案内に従います。

この教材の文章を保存する用途は無料プランの**GitHub Free**から始められます。プラン選択が出た場合も、有料プランやCopilotの契約は必要ありません。

登録が終わり、GitHubで自分のプロフィールメニューを開けるようになれば、次へ進めます。メール確認が未完了だとリポジトリ作成などが制限されるため、確認の案内が残っていれば済ませてください。[GitHub公式の登録手順](https://docs.github.com/en/account-and-profile/how-tos/account-management/creating-an-account-on-github)・[プランの説明](https://docs.github.com/en/get-started/learning-about-github/githubs-plans)

## 3. 次回からGoogleでログインする

1. [GitHubのログインページ](https://github.com/login)を開きます。**Sign in**は「ログイン」という意味です。
2. **Continue with Google**を押します。
3. **登録したときと同じGoogleアカウント**を選びます。Googleへのログインを求められた場合は、Googleの画面で行います。
4. GitHubで追加の本人確認が表示されたら、設定済みの方法で確認します。
5. プロフィールメニューなどで、登録したGitHubのユーザー名になっていることを確認します。

GoogleのパスワードはGoogleのログイン画面に入力します。GitHubの通常のパスワード欄にGoogleのパスワードを入れる手順ではありません。

GitHubで2要素認証（ログイン時にもう一段階本人確認をする機能）を設定している場合は、Googleでログインした後にも確認が必要になることがあります。[GitHub公式のログイン方法の説明](https://docs.github.com/en/authentication/keeping-your-account-and-data-secure/about-authentication-to-github)

## 4. 自分用の学びのノートを作る

ログインできたら、[はじめ方の「自分用の場所を作る」](getting-started.md#自分用の場所を作る)へ戻ります。

**Use this template → Create a new repository → Private**の順に、自分用の保存場所を作ります。登録しただけではノートはまだ作られていません。

自分用のリポジトリができたら、そのページをブラウザーのお気に入りに保存すると、次回から開きやすくなります。

## うまくいかないとき

### Googleアカウントがいくつも表示される

登録に使った保護者のアカウントを選びます。勤務先・学校のアカウントは管理者の制限や利用終了の影響を受ける場合があるため、家庭で長く管理できる個人のアカウントを使うと続けやすくなります。

### ログインしたはずなのに、新規登録の画面になる

別のGoogleアカウントを選んでいないか確認します。既存のノートがある場合は、そのまま新しいGitHubアカウントを作らず、登録時のアカウントで入り直してください。

### すでにメールアドレスとパスワードでGitHubに登録している

まず、これまでの方法で既存のGitHubアカウントにログインします。Googleでのログインを使うには、そのGoogleのメールアドレスを既存のGitHubアカウントに追加する方法があります。新規登録をやり直す前に、[公式説明の「Social login」](https://docs.github.com/en/authentication/keeping-your-account-and-data-secure/about-authentication-to-github#authenticating-in-your-browser)を確認してください。

### Googleアカウントのパスワードを忘れた

[Googleのアカウント復元ページ](https://accounts.google.com/signin/recovery)から復元します。GitHubのパスワード再設定では、Googleのパスワードは変更できません。

### Googleアカウントを作らずに使いたい

GitHubはメールアドレスとパスワードでも登録できます。[GitHubの新規登録ページ](https://github.com/signup)から案内に従って登録し、その方法でログインしてください。

## 登録後に確認しておくこと

- GitHubのユーザー名と、登録に使ったGoogleのメールアドレスを保護者が把握しておく。
- GitHubが案内する[2要素認証の設定](https://docs.github.com/en/authentication/securing-your-account-with-two-factor-authentication-2fa/configuring-two-factor-authentication)を確認し、復旧用のコードは学習ノートの外で保管する。
- パスワードや確認コードは、学習記録・公開コメント・AIへの相談文に書かない。
