# 探究に伴走する

## 「ふしぎ」から、小さく1回

1. **見つける** — 散歩・読書・工作で気になったことを、そのまま残す。
2. **予想する** — 「どうなると思う？」。予想しなくても始められます。
3. **ためす・調べる** — 比べる条件を1つに絞る。本で調べる、詳しい人に聞く方法でもよい。
4. **残す** — 見たこと・測ったことと、考えたことを別々に書く。
5. **ふりかえる** — 予想と違った点、まだわからない点、次の問いを選ぶ。

結果が出ない、失敗する、興味が移ることも記録です。「続けない」も本人が選べます。

## 年齢に合わせる

- 低学年: 写真や絵を見ながら、一言だけ聞く。保護者が書いた場合は代筆と明記。
- 高学年: 本人の問い・予想・方法・結果を整理する。数値がなければ無理に付けない。
- どの学年でも: 書く量、頻度、見せる相手を本人と相談する。

「すごい実績」に言い換える必要はありません。保護者が覚えている内容は「保護者の観察」、本人が実際に言った言葉だけを「本人のことば」に残します。記憶が曖昧なら要約と明記します。

## 身近な問いの入口

- 紙の折り方を変えると、橋の支え方はどう変わる？
- 同じ場所の影は、時間が変わるとどこへ動く？
- 読んだ本の主人公は、別の選び方もできたかな？

これは提案です。実施済みの活動として記録しません。
火・薬品・電源・水辺・生き物の採取などを伴う活動は保護者が安全性や場所のルールを確認し、無理なくできる方法を選びます。
