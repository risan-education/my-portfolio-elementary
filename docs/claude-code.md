# 補足: Claude Codeを使う（保護者向け）

- 作成日: 2026-09-26
- 更新日: 2026-09-26

保護者が設定・操作できる場合の選択肢です。[はじめ方](getting-started.md)と同じく、自分用のPrivateリポジトリで使います。[確認状況](connection-check.md)にあるとおり、各環境での通し検証は未実施です。

Claudeの個人アカウントは18歳以上が条件です。中学生へのGitHub移譲と、Claudeアカウントの利用開始は別です。[公式の年齢条件](https://support.claude.com/en/articles/13117299-minimum-age-requirement-access-restriction)

## 指示書を読む

CLAUDE.mdの @AGENTS.md で共通ルールを取り込む構成です。読み込み方は設定・バージョンにも依存します。最初に次の一文を送り、読み取れたことを確認します。

> AGENTS.mdを読んで、記録を始める準備をしてください。

指示書は行動の指針であり、アクセス制御や動作の保証ではありません。[公式の指示書の説明](https://code.claude.com/docs/en/memory)

## 実行方法を選ぶ

画面がデスクトップかWebかだけでなく、処理をどこで実行するかを確認します。デスクトップやターミナルからクラウドを使うこともあります。[公式のクラウド実行の説明](https://code.claude.com/docs/en/claude-code-on-the-web)

| 実行方法 | 本教材での扱い |
| --- | --- |
| ローカル実行 | 自分用Privateをパソコンにcloneし、mainの最新状態を確認して作業。保存を頼んだらmainへコミット・pushし、GitHubで再確認 |
| クラウド実行 | 作業ブランチや権限制限がある場合はmain直接保存と同じ手順にならない。初心者向けの標準ルートにはしない |

PRなしで使いたい場合は、mainへの保存権限があるローカル実行などを選びます。実行環境の制限を回避するための強制pushや保護解除はしません。

クラウドを選ぶ場合は、作業開始前にmainへの反映方法を確認します。利用者が作業ブランチ・PR・マージを了承した場合だけ、その方法で進めます。作業ブランチに保存しただけなら「mainには未反映」と伝え、mainへの反映と再読込を確認して完了にします。

## 記録を作る

[架空の記録での接続確認](connection-check.md)から始めます。以後は「記録の案を作って」「この内容で保存してください」で進められます。

ChatGPTと併用するときは、同じ記録を同時に編集せず、もう片方の保存を終えてから最新を読み直します。端末内の記録やGit履歴もAIに送られる可能性があるため、[利用範囲](record-choices.md)を先に確認します。AIに渡さない情報を同じ作業場所へ置きません。

## 困ったとき

- mainに見当たらない: 保存先ブランチと未反映の変更を確認する。
- 指示書を読めていない: 対象リポジトリを確認してAGENTS.mdを読むよう頼む。
- クラウドセッションを共有したい: Privateリポジトリの設定と会話・セッションの共有設定は別。実記録を含むセッションを公開しない。
- 権限や競合のエラー: 変更を捨てず、下書きを残して原因を確認する。
