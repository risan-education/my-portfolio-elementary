# 補足: Claude Code を使う（自分で設定できる方向け）

- 作成日: 2026-09-26
- 更新日: 2026-09-26

この教材の基本の手順は[はじめ方](getting-started.md)のChatGPTです。初めての方はそちらを使ってください。
このページは、Claude Code の契約・インストール・GitHub接続を自分で済ませられる方向けの短い補足です。手順の詳細は書きません。

## 前提

- Claude Code はターミナル、デスクトップアプリ、Web版（claude.ai/code）、IDE拡張で使えます。契約条件と導入手順は[公式ドキュメント](https://code.claude.com/docs/)で確認してください。
- 対象は配布元ではなく、[はじめ方](getting-started.md)で作った**自分用のPrivateリポジトリ**です。
- 保護者が操作します。子どもの本名・学校名など不要な個人情報を送らない点はChatGPTと同じです。

## 指示書の読み込み

リポジトリ直下の `CLAUDE.md` は「AGENTS.md を読む」とだけ書いた案内です。Claude Code は `AGENTS.md` を自動で読み込みますが、読めていないと感じたら最初に次のように頼みます。

> AGENTS.mdを読んで、記録を始める準備をしてください。

以降の依頼のしかた（「記録の案を作って」「この内容で保存してください」）は[AIに整理を頼むとき](ai-guide.md)と同じです。

## 保存先とブランチ

- **デスクトップアプリ・ターミナル**: 自分用リポジトリをパソコンに clone し、`main` で作業して `origin/main` へ push します。AGENTS.md の「mainへ直接保存」がそのまま使えます。
- **Web版（クラウド実行）**: セッションごとに `claude/...` のような作業用ブランチが割り当てられ、そこへ push されます。これは Claude Code の仕様で、AGENTS.md の違反ではありません。作業後に GitHub 上で `main` へマージするか、pull request を作ってマージしてください。マージしないと `main` の記録は増えません。
- どちらの場合も、保存後に GitHub で `main` の内容と日付を確認します。

## 困ったとき

- **`main` に反映されない**: Web版なら作業ブランチに残っています。GitHub でブランチを開き、マージします。
- **指示書が効いていない**: 会話の最初に AGENTS.md を読むよう明示します。日付・本人の言葉の扱いは[日付のルール](file-dates.md)で再確認を頼めます。
- **Claude Code と ChatGPT を併用する**: どちらも同じ `main` を編集します。片方で保存したら、もう片方は作業前に最新を取り込んでから編集します。
