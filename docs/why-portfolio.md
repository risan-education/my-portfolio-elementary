# なぜ小学生のうちからMyポートフォリオを作るのか

- 作成日: 2026-09-27
- 更新日: 2026-10-02

この教材で小学生が作るMyポートフォリオは、主に「探究学習メモ」です。「なんで？」と思ったこと、やってみたこと、うまくいかなかったことを、本人の言葉のまま残します。ここでは、その目的と、公的資料・研究から分かる続けるメリットをまとめます。出典の確認日は2026-09-27です。

入試や就職の結果を保証する教材ではありません。文部科学省の資料も、本人の意思に反する記録を強いたり、無理な対話に結び付けたりしないよう求めています（出典2）。記録の量や頻度を目標にせず、そのときの興味を大切にします。

## 四つの目的

1. **探究学習に慣れるための練習。** 小学校学習指導要領は、総合的な学習の時間で「①課題の設定→②情報の収集→③整理・分析→④まとめ・表現」の探究のプロセスを繰り返すことを重視しています（出典1）。家庭の「なんで？」を一言残し、「つぎは何をためす？」と考えることが、この入口になります。
2. **自分がやりたいことを探す練習。** 何に夢中になり、何を途中でやめ、何をまた始めたかを本人の言葉で残すと、あとで本人が「好き」「得意」「苦手」を見つける材料になります。少数の記録から大人やAIが性格や適性を決めつける材料にはしません。
3. **将来の推薦入試や就職活動にも役立つ。** 大学の総合型選抜・学校推薦型選抜や就職活動では、本人が書く活動報告書・志望理由・面接で「なぜ始めたのか」「どう考えたのか」を問われます（出典3）。小学生の記録がそのまま提出物になるわけではありませんが、自分の言葉で経験を説明する練習と、中学・高校の探究の出発点になります。
4. **AIを使うときのコンテキストとしても役立つ。** 本人が確認した記録は、ChatGPTなどに自分の背景を伝える「外部記憶」になります。原記録を変えず、渡す範囲は本人が選びます。詳しくは[将来の使いみち](future-use.md)を参照してください。

公的資料・研究は設計の参考です。以下の自己調整学習への指導の研究結果は、この家庭用テンプレートやAIとの対話そのものの効果を測定したものではありません。

## 続けるメリット（3点）

### 1. 振り返る習慣が「学びに向かう力」を育てる

- 文部科学省は2020年4月から、すべての小学校・中学校・高等学校で「キャリア・パスポート」（児童生徒が活動を記録し蓄積するポートフォリオ）を実施することにしました。その目的は、小学校から高等学校を通じて、児童生徒が「自らの学習状況やキャリア形成を見通したり、振り返ったりして、自己評価を行うとともに、主体的に学びに向かう力を育み、自己実現につなぐもの」とされています（出典2・出典4）。
- 小学校学習指導要領解説は、全国学力・学習状況調査の分析で「総合的な学習の時間で探究のプロセスを意識した学習活動に取り組んでいる児童生徒ほど各教科の正答率が高い傾向にあること」が明らかになったと述べています（出典1）。相関であり、記録が成績を上げると証明したものではありません。
- 小学生を対象にした49研究・中高生を対象にした35研究のメタ分析では、計画・見直し・自己評価などの「自己調整学習」を教える介入の平均効果量は0.69で、小学校段階でも効果的に育てられると結論しています（出典5）。
- OECDのラーニング・コンパス2030は、「予測→行動→振り返り」のサイクルを示し、振り返りを通して学習者は「自分の将来の行動に対する見通しと力の感覚」を得て、エージェンシー（自分で選び行動する力）が育つとしています（出典6）。

この教材の[ふりかえり](../templates/reflection.md)や[年間ふりかえり](../templates/annual-review.md)は、この「見通し・振り返り・自己評価」を家庭で無理なく行うための用紙です。

### 2. 消えてしまう「そのときの言葉と気持ち」を、自己理解の材料として残せる

- 小学校学習指導要領解説は、体験活動を行ったときの感覚や思いは「時間の経過とともに薄れていき、忘れ去られる」が、「貴重なものであり、その後の課題解決に生かしたい情報である」ため、言語化して蓄積するよう求めています（出典1）。
- キャリア・パスポートは、教科学習だけでなく「学校外の活動（ボランティア等の地域活動、家庭内での取組、習い事などの活動）」を含めて振り返り、小学校入学から高等学校卒業まで持ち上がることを前提にしています。また、家族などの大人が対話的に関わることで「自己有用感の醸成や自己変容の自覚」に結び付けるとしています（出典2）。
- 国立教育政策研究所は、小学6年生の記録を中学1年生の12月に読み返し、「時間や場面を越えて自己の成長や変容を自覚する『自己理解』につなげる」実践を紹介しています（出典7）。

本教材が本人の言葉を書き換えず、保護者の要約・観察・AIの提案と分けて原記録を保持するのは、この「あとから本人が読み返す」ためです。

### 3. 将来、自分の言葉で経験を説明する材料になる

- 令和8年度大学入学者選抜実施要項は、総合型選抜について「入学志願者本人の記載する資料」（活動報告書、大学入学希望理由書、学修計画書等）を「積極的に活用する」としています。活動報告書に記載を求めるのは「高等学校までの学習や活動の履歴」で、総合的な探究の時間の課題研究や、学校内外で意欲的に取り組んだ活動が例示されています（出典3）。小学生の記録が提出物になるわけではありません。
- 文部科学省のQ&Aは、キャリア・パスポートを入試や就職試験でそのまま使うことは適切でないとしつつ、「児童生徒自らが入学者選抜や就職試験で面接を受けたり自己申告書に記入したりする際の情報の一つとして『キャリア・パスポート』を参考とすることは考えられます」としています（出典4）。本教材の記録も同じ位置づけで、本人が自分の言葉で説明するための材料です。
- 就職活動や社会人になってからも、「なぜ始めたか」「何に困ったか」「どう考えたか」を本人の記録から拾えます。同じ記録を、ChatGPTなどのAIに自分の背景を伝えるコンテキストとして根拠付きで渡せます（[将来の使いみち](future-use.md)、[今の自分をAIに伝える](../templates/ai-context.md)）。

提出物を作るときは、提出先の年度・設問・AI利用条件を[提出条件の確認用紙](../templates/submission-check.md)で確認します。小学生の経験を大学時代の経験に置き換えず、記録にないことを補いません。
