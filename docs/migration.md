# 中学生になったら

- 作成日: 2026-09-25
- 更新日: 2026-09-26

中学生版は別途整備予定です。この小学生版のまま使い続けても構いません。フォルダ構成と用紙はそのまま中学・高校でも使えます。

## 引き継ぎの手順

1. [バックアップと復元の手順](backup-and-restore.md)で、記録と外部原本の控えが開けることを確認する。
2. 本人と、引き継ぎたい記録・見せたくない記録を確認する。[利用停止・削除の手順](record-choices.md)を確認し、不要な記録をそのまま引き継がない。
3. 元のファイル名・日付・本人の言葉を保ち、あとからの解釈を当時の記録に混ぜない。
4. 続いている探究には元記録へのリンクを付け、新しい行動や問いを追記する。[問いの台帳](../questions.md)の「途中」「お休み」の問いが出発点になる。
5. 新しいリポジトリへ移す場合もPrivateを確認し、リンクと画像の参照先を点検する。

「当時はこう思っていた」「今はこう考える」を分けて残します。小学生の文章を入試向けの表現に置き換える必要はありません。

## 本人にリポジトリを渡す

GitHubのアカウントは原則13歳以上です。本人が自分のアカウントを持てる年齢になり、本人が望むときに、保護者のアカウントから本人へ渡せます。

1. 本人が保護者と相談して自分のGitHubアカウントを作り、2要素認証を設定する。
2. 保護者のリポジトリの Settings → Danger Zone → **Transfer ownership** で本人のアカウントへ移す。移した後もPrivateのままであることを確認する。公式手順: [リポジトリの移譲](https://docs.github.com/en/repositories/creating-and-managing-repositories/transferring-a-repository)
3. 移した後、保護者を共同編集者として残すか外すかを本人が決める。個人所有のPrivateリポジトリでは、公式資料上、共同編集者を読み取り専用にはできない。閲覧だけにしたい場合は、本人が選んだ資料のコピーを別に共有する。[GitHubの権限説明](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/repository-access-and-collaboration/permission-levels-for-a-personal-account-repository)
4. ChatGPTなどの接続は、本人のアカウントであらためて設定する。保護者側の古い接続は解除する。

渡すタイミングは家庭ごとに違います。渡した後は、何をAIに渡すか、何を残すかを本人が決めます。詳しくは[将来の使いみち](future-use.md)を参照してください。

## 中学生本人がAIを使うとき

本人が自分のアカウントで記録を続ける場合、[中学生とCopilotの無料利用](copilot-students.md)に年齢と学生認証の条件があります。ChatGPTやClaude Codeも年齢条件と保護者の同意の要件を各サービスで確認してください。

GitHubとAIサービスの年齢条件は別です。Claudeの個人アカウントは18歳以上が条件のため、中学生本人への移行先として案内しません。保護者が使う場合も本人の情報の利用範囲を確認します。[Claudeの年齢条件](https://support.claude.com/en/articles/13117299-minimum-age-requirement-access-restriction)（確認日: 2026-09-26）
