# 中学生になったら

中学生版は別途整備予定です。この小学生版のまま使い続けても構いません。

1. 現在の記録と写真の控え、外部保管先をバックアップする。
2. 本人と、引き継ぎたい記録・見せたくない記録を確認する。
3. 元のファイル名・日付・本人の言葉を保ち、あとからの解釈を当時の記録に混ぜない。
4. 続いている探究には元記録へのリンクを付け、新しい行動や問いを追記する。
5. 新しいリポジトリへ移す場合もPrivateを確認し、リンクと画像の参照先を点検する。

「当時はこう思っていた」「今はこう考える」を分けて残します。小学生の文章を入試向けの表現に置き換える必要はありません。
