# 記録を残す・使う範囲を本人と決める

- 作成日: 2026-09-26
- 更新日: 2026-09-26

「残してよい」「AIに渡してよい」「人に見せてよい」「提出に使ってよい」は別々に相談します。小学生の間も、本人にわかる言葉で聞きます。理由を説明したくない場合も尊重します。

## いつ相談する？

記録するとき、写真を添えるとき、外部へ渡す前、進学時などに見直します。「今日は残したくない」「あとで決めたい」も選べます。
保護者が代筆した観察を、本人が同意した考えと扱いません。

必要なときだけ[利用範囲の確認メモ](../templates/record-use-review.md)を使います。毎日の記録への追加記入は不要です。AI利用を許可しない記録の一覧自体にも個人情報がある場合は、AIと接続していない場所に保管します。

## AIに渡さない情報

同じリポジトリに「AIは読まないで」と書くだけでは閲覧を技術的に遮断できません。AIに渡さない情報は、接続していない別の保管先に置きます。必要な記録だけを選んだコピーでAIを使う方法もあります。
.gitignoreはアクセス制御ではなく、すでに保存したGit履歴も消しません。

## 利用をやめたい・削除したいとき

1. まず対象のAI利用・共有を止めます。必要なら接続や共有リンクを解除します。
2. 本人と「今後の利用停止」「別の保管先へ移す」「削除」を区別して決めます。
3. 元記録だけでなく、questions.md、要約・提出用下書き、AI向け自己紹介、添付画像、外部原本、バックアップにコピーや引用がないか確認します。
4. 最新版から削除してもGit履歴に残ります。履歴までの削除を望む場合は、対象と影響を確かめ、詳しい人と[GitHubの削除手順](https://docs.github.com/en/authentication/keeping-your-account-and-data-secure/removing-sensitive-data-from-a-repository)を確認します。AIに無条件の履歴書き換えや強制pushを任せません。
5. 他の端末のコピー、AIサービス内の会話・保存情報、外部保管先もそれぞれ確認します。管理できないコピーがある場合、完全に消えたとは断言しません。
6. 利用停止した内容を後のバックアップ復元や要約再生成で戻さないようにします。管理メモには削除内容そのものを再記録しません。

「元記録を保持する」は記録を美化しないための原則です。本人の利用停止・削除の希望を妨げるものではありません。記録をすべて持ち続ける義務はありません。
