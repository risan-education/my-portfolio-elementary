# はじめ方（保護者向け）

- 作成日: 2026-09-25
- 更新日: 2026-10-02

保護者がスマホのChatGPTに子どもの体験を伝え、GitHubの非公開の保存場所に記録する手順です。操作は保護者が行います。

## 準備の流れ

1. 保護者用のGoogleアカウントを作成する。
2. ChatGPTの有料プランを契約する（Plus以上。Plusの目安は月額約3,000円）。
3. スマホにChatGPTアプリをインストールし、Googleでログインする。
4. 保護者用のGitHubアカウントを用意する。
5. 本テンプレートを保護者のGitHubにコピーし、Privateに設定する。
6. コピーしたリポジトリにChatGPTから接続する。

登録済みのアカウントや契約済みのプランは、そのまま使えます。

## 1. 保護者用のGoogleアカウントを作成する

Googleアカウントは、ChatGPTやGitHubにログインするときに使います。保護者がGmailなどで使っているものがあれば、新しく作る必要はありません。

1. スマホのSafariやChromeで[Googleの登録ページ](https://accounts.google.com/signup)を開きます。
2. 用途を聞かれたら、**「個人で使用」「自分用」**などを選びます。
3. 保護者の名前・生年月日などを入力し、メールアドレスとパスワードを設定します。
4. 確認コードや利用規約の画面が出たら、案内に沿って登録を完了します。

以後の手順では、同じGoogleアカウントを使います。[Google公式の登録手順](https://support.google.com/accounts/answer/27441?hl=ja)

## 2. ChatGPTの有料プランを契約する

このガイドは**Plus以上のプランを使う流れ**で説明します。初めて契約する場合は、Plusを選びます。

1. スマホのブラウザーで[ChatGPT](https://chatgpt.com/)を開きます。
2. 登録・ログイン画面で**「Googleで続ける（Continue with Google）」**を選び、手順1のアカウントで入ります。
3. プロフィールや設定から、**プランのアップグレード**を開きます。
4. **Plus**を選び、表示される月額・更新条件・支払い方法を確認して契約します。

**Plusの予算目安は月額約3,000円**です。公式案内は月額20米ドルで、約3,000円は1ドル150円で換算した例です。実際の金額は通貨・税・購入方法などで異なるため、契約画面を確認してください。上位プランの料金は別です。[公式プラン案内](https://learn.chatgpt.com/docs/pricing)

GitHubへの保存に使える機能は、プランだけでなく接続にもよります。手順6で読み書きを確認します。

## 3. スマホにChatGPTアプリを入れてGoogleでログインする

1. **iPhoneはApp Store、AndroidはGoogle Play**を開きます。
2. 「ChatGPT」を検索し、**提供元がOpenAIの公式アプリ**をインストールします。
3. アプリを開き、**ログイン → Googleで続ける**を選びます。
4. **手順2で契約したGoogleアカウント**を選びます。
5. 設定のアカウント・プラン表示で、契約が反映されていることを確認します。

無料プランと表示される場合は、選んだアカウントを確認します。アプリで再契約する必要はありません。

## 4. 保護者用のGitHubアカウントを用意する

GitHubは、記録を変更履歴と一緒に保存できるサービスです。**リポジトリ**は「ノートをまとめて入れる保存場所」のことです。

1. スマホのブラウザーで[GitHubの登録ページ](https://github.com/signup)を開きます。
2. **Continue with Google（Googleで続ける）**を選び、保護者のGoogleアカウントで登録します。
3. **Username（ユーザー名）**を決めます。子どもの本名や学校名は入れません。
4. メール確認などを済ませ、自分のGitHubにログインできれば完了です。

GitHubは無料アカウントから始められます。詳しい画面の説明は[GitHubの登録とログイン](github-basics.md)、登録方法の出典は[GitHub公式案内](https://docs.github.com/en/account-and-profile/how-tos/account-management/creating-an-account-on-github)です。

## 5. テンプレートをコピーしてPrivateに設定する

**Private（プライベート）は「非公開」**という意味です。コピーを作るときに選びます。

### 自分用の場所を作る

1. GitHubにログインした状態で、[本テンプレートのトップページ](https://github.com/risan-education/my-portfolio-elementary)を開きます。
2. **Use this template → Create a new repository**を選びます。「このひな形から自分用の保存場所を作る」という操作です。
3. **Owner（所有者）**に、保護者のアカウントを選びます。
4. **Repository name（保存場所の名前）**に、例えば `family-learning-notes` と入力します。
5. **Private**を選びます。**Include all branches**はチェック不要です。
6. **Create repository from template**を押します。
7. 作成されたページで、名前のそばに**Private**と表示されていることを確認します。

作成したページのURLをコピーし、お気に入りにも保存します。次の手順では、この**自分用のURL**を使います。[GitHub公式のコピー手順](https://docs.github.com/en/repositories/creating-and-managing-repositories/creating-a-repository-from-a-template)

## 6. コピーしたリポジトリにChatGPTから接続する

### GitHubとの接続を設定する

1. スマホのブラウザーで[ChatGPTのプラグイン一覧](https://chatgpt.com/plugins)を開きます。手順2と同じアカウントでログインします。
2. **GitHub**を検索し、提供元・対応する機能を確認して追加します。
3. **接続（Connect）**などの案内から、保護者のGitHubにログインします。
4. アクセスを許可するリポジトリを選べる場合は、手順5で作ったものを選び、権限を確認して許可します。
5. ChatGPTアプリに戻り、新しい会話を開きます。GitHubの利用を選ぶ画面が出たら選択します。

プラグインはChatGPTと外部サービスをつなぐ機能です。スマホで使えるものや表示名は環境により異なります。見つからない場合は下の「困ったとき」を確認してください。[OpenAI公式の接続手順](https://learn.chatgpt.com/docs/plugins)

### 自分用のURLを伝える

次の文の［ ］を、手順5でコピーしたURLに置き換えて送ります。

> 保存先は［自分用PrivateリポジトリのURL］です。AGENTS.mdを読んで、記録を始める準備をしてください。

**AGENTS.mdは、この教材に入っているAI用の指示書**です。ChatGPTが読んだうえで、保存先がPrivateか、記録を読んだり保存したりできるかを確認します。

### 保存できるか練習する

準備ができたら、[接続確認の練習](connection-check.md)で、練習用の文章を保存して読み返します。**接続できることと、ファイルを保存できることは別**です。練習が成功したら、実際の記録を始めます。

## 準備ができたら、一言を残す

1. 活動日・やったこと・子どもが言った言葉を、ChatGPTに送ります。
2. 返ってきた文章を読み直します。質問には答えられる範囲で答え、「もう十分です」で終えても構いません。
3. 内容がよければ、**「この内容で保存してください」**と送ります。
4. 返されたGitHubのリンクを開き、文章が保存されていることを確認します。

新しい会話では、自分用のURLと「AGENTS.mdを読んで、記録を始める準備をしてください」を最初に送ります。

[一言だけの例](../examples/prompts/06-one-line.md) ／ [19種類の使い方](../examples/prompts/README.md) ／ [記録の探し方](finding-records.md)

## 困ったとき

| 困ったこと | 確認すること |
| --- | --- |
| アプリでPlusにならない | 契約時と同じGoogleアカウントか確認する |
| Use this templateが見つからない | GitHubにログインし、配布元のトップページを開く |
| GitHubのプラグインが見つからない・スマホで使えない | ブラウザーの一覧と対応端末を確認する。使えなければ下の手動保存を使う |
| コピーした保存場所が出てこない | GitHub接続で許可したアカウントとリポジトリを確認する |
| 読めるが保存できない | 接続の書き込み機能・権限を確認する。対応していなければ手動保存する |
| mainへの保存が拒否される | 拒否の理由を確認する。保護設定を勝手に解除しない |

## 補足: 自分でファイルを編集するとき

<details>
<summary>ChatGPTの文章案をGitHubで手動保存する</summary>

1. ChatGPTに「保存先のファイル名と、保存用のMarkdown全文を見せて」と頼みます。Markdownは、この教材で使う文章ファイルの形式です。
2. 自分用Privateリポジトリで **Add file → Create new file**を選びます。
3. 提案されたファイル名と本文を入力します。同名ファイルがある場合は上書きせず、別名にします。
4. **Preview**で確認し、**Commit changes（変更を保存）**からmainに保存します。
5. `index.md`も開き、記録の行を追加します。追記だけなら既存行の最終更新を直します。

一覧の行もChatGPTに案を作ってもらえます。本人の新しい問いがあれば、`questions.md`への追加案も確認します。[保存先の説明](finding-records.md)

</details>

## ときどき手元にも保存する

自分用リポジトリで **Code → Download ZIP**を選ぶと、現在のファイルの控えを取れます。変更履歴や外部の写真・動画は含まれません。詳しくは[バックアップ](backup-and-restore.md)を参照してください。
