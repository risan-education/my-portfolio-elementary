# 記録の保存先・一覧・呼び出し方

- 作成日: 2026-10-02
- 更新日: 2026-10-02

「どこに保存されたのか」「あとでどう開くのか」「全部の一覧はどこか」をまとめます。保護者モードでも本人モードでも同じです。

## 1. 何がどこに保存されるか

ChatGPTは内容から用紙を選び、用紙ごとに決まったフォルダへ保存します。ファイル名は `YYMMDD-theme.md`（例: 2026年10月3日のダンゴムシ → `261003-dangomushi.md`）です。

| 記録の種類 | 用紙 | 保存先 | ファイル名の例 |
| --- | --- | --- | --- |
| 日々の一言、体験、読書、習い事 | ひとこと記録、体験の記録 | `experiences/` | `experiences/261003-dangomushi.md` |
| 続けて調べる探究 | 探究ノート | `projects/` | `projects/261015-dangomushi-inquiry.md` |
| 工作・絵・プログラムなどの作品 | 作品カード | `projects/` | `projects/261012-danborobo.md` |
| 複数の活動をつなげる計画 | 家庭の単元づくりシート | `projects/` | `projects/261020-packaging-unit.md` |
| ときどきのふりかえり | ふりかえり | `reflections/` | `reflections/261031-october.md` |
| 1年のふりかえり | 年間ふりかえり | `annual-review/` | `annual-review/270331-2026.md` |
| 本人の「なんで？」の一覧 | （台帳） | `questions.md` | 1ファイルに行を足す |
| 好きなこと・興味 | （任意のメモ） | `profile/README.md` | 1ファイルに追記 |
| 根拠付き要約、報告書の下書き、AI向け自己紹介 | 根拠付き要約、AIに渡す現在の情報、提出条件の確認 | `derived/` | `derived/320601-activity-report.md` |
| 写真・PDFの控えと所在メモ | （所在メモ） | `assets/` | `assets/261012-danborobo-location.md` |

前の記録への追記は、新しいファイルを作らず、同じファイルの末尾に日付付きで足されます。

## 2. 一覧（リスト）はどこにあるか

- **記録一覧 [index.md](../index.md)**: 保存した記録の目次。新しい記録を保存するたびに、ChatGPTが活動日・種類・題名・ファイルへのリンク・記録者を1行足します。活動日の新しい順です。過去の活動をあとから保存するときも活動日の位置へ入れます。日付不明は末尾です。
- **問いの台帳 [questions.md](../questions.md)**: 本人の「なんで？」だけを集めた一覧。状態（未着手／途中／ひと区切り／お休み）が分かります。
- **フォルダそのもの**: GitHubで `experiences/` などを開くと、ファイル名の日付順に並びます。一覧ファイルがなくても、ここで探せます。

`examples/`（架空例）と `templates/`（空欄の用紙）は一覧に載りません。

## 3. ChatGPTで呼び出す

保護者モードでは、題名やテーマ、日付で頼むだけで ChatGPT が探して開きます。ファイル名を覚えておく必要はありません。

```text
ダンゴムシの記録を見せて
```

```text
10月に保存した記録を一覧にして
```

```text
探究ノートで「途中」のものを一覧にして
```

```text
questions.md で「未着手」の問いを見せて
```

```text
きのう保存した記録を開いて
```

```text
index.md を見せて
```

ChatGPTは [index.md](../index.md) とフォルダ内のファイル名から候補を探します。「保存した月」は活動日と区別し、原記録の作成日を確認します。探究の状態は原記録を開いて確認します。そのうえで、見つかった記録のリンクと本文（冒頭の「きょうのこと（にっき）」から）を返します。同じ名前の記録が複数あるときは、日付を添えて候補を示します。

本人モードでは、保護者が子どもの「まえのだんごむしのきろく、よんで」を伝えると、「きょうのこと（にっき）」を子ども向けに読み上げやすい形で返します。

## 4. 自分で開く（GitHubの画面）

1. 自分用のPrivateリポジトリを開きます。
2. `index.md` を開くと、記録の一覧とリンクがあります。リンクを押すとその記録が開きます。
3. フォルダから探す場合は `experiences/` などを開き、ファイル名の日付で選びます。

記録のURLは `https://github.com/（自分のユーザー名）/（リポジトリ名）/blob/main/experiences/261003-dangomushi.md` のような形です。

## 5. 一覧が合わなくなったとき

index.md に行が足りない、リンクが切れている、というときは保護者モードで次のように頼みます。

```text
index.md をフォルダの中身と照らし合わせて、足りない行を足して
```

原記録を確認して不足行を足し、リンクや最終更新の誤りを直します。既存の行を無断で消さず、利用停止・削除済みの記録を再登録しません。ファイルが見つからない場合は、削除・移動などの理由を確認します。
