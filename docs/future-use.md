# 将来の使いみち: 探究・入試・就活・AIのコンテキスト

- 作成日: 2026-09-26
- 更新日: 2026-09-26

このリポジトリは、小学生のときの「なんで？」を残すだけでなく、そのあと何十年も使える「自分自身の一次情報」を目指しています。ここでは、あとからどう使うかと、そのときに守ることをまとめます。

小学生の段階で、入試や就活のために記録を増やしたり整えたりする必要はありません。ここに書いた将来の使い方は、記録を盛らずに続けるための見通しです。

## 時期ごとの使い方

| 時期 | 使い方 | 関係する場所 |
| --- | --- | --- |
| 小学生 | 体験・問い・作品を残す。年に一度、本人が思い出を選ぶ | `experiences/` `projects/` `annual-review/` `questions.md` |
| 中学・高校 | 続いている問いを探究学習の出発点にする。発表や報告書の根拠に使う | `questions.md` `derived/` |
| 大学入試（総合型・学校推薦型） | 活動報告書・志望理由書の下書きを、根拠リンク付きで作る。面接の想定問答を記録から作る | `derived/` |
| 大学生（就職活動） | 「なぜ始めたか」「何に困ったか」「どう考えたか」「人とどう関わったか」「失敗から何を学んだか」を記録から拾う | `derived/` |
| 社会人 | 自分の考え方・経験・失敗をAIに伝えるコンテキストとして使う | `derived/` と原記録 |

どの段階でも、**原記録は書き換えず、派生文書を別に作ります**。派生文書のルールは [derived/README.md](../derived/README.md) にあります。

## 中高の探究学習につなぐ

- [問いの台帳](../questions.md)を開き、状態が「途中」「お休み」の問いや、何度も出てくる言葉を本人と眺めます。続けるかどうかは本人が決めます。
- 続ける場合は[探究ノート](../templates/inquiry.md)を新しく作り、「きっかけの体験記録」に小学生時代の記録をリンクします。当時の考えと今の考えを分けて書きます。
- 小学生の文章を書き直す必要はありません。「当時はこう言っていた」が、そのまま探究の出発点の証拠になります。

## 入試・就活の書類に使う

1. [根拠付き要約](../templates/evidence-summary.md)を `derived/` に作り、対象期間の原記録を一覧にします。
2. 各段落に根拠リンクを付けます。記録にないことは書きません。「根拠が足りない」項目は正直に残します。
3. 本人が読み直し、使いたくない記録を外します。
4. 提出用の文章は、派生文書の下書きから本人が仕上げます。AIに全文を書かせて提出しません。

面接対策では、記録から「なぜそれをしたの？」「うまくいかなかったとき、どうした？」「誰に相談した？」といった問いをAIに作ってもらい、本人が自分の言葉で答える練習ができます。想定回答をAIに作らせて暗記する使い方は勧めません。

盛らない・断定しないルールは [AGENTS.md](../AGENTS.md) にあります。少ない記録から「粘り強い」「リーダーシップがある」などと決めつける文章は、書類でも面接でも根拠を問われます。

## AIに渡すコンテキストとして使う

新しいAIとの会話で自分の背景を伝えるとき、このリポジトリはそのまま「自分のデータベース」になります。

- **渡す順番**: まず `derived/` の根拠付き要約、次に必要な期間の原記録。全部を毎回渡す必要はありません。
- **渡さないもの**: 本人が残したくないと言った記録、他人の個人情報、写真の原本。渡す前に[個人情報の扱い](privacy.md)を確認します。
- **AIへの前置き**: 「これは本人の一次記録です。書かれていないことを補わず、性格や能力を断定せず、根拠のファイル名を示してください」と伝えます。
- **本人の同意**: 中学生以降は、何をAIに渡すかを本人が決めます。保護者が代わりに渡し続けません。
- **AIの出力の扱い**: AIが作った要約や提案は派生文書に保存し、原記録には混ぜません。使ったAIと日付を書きます。

## 依頼例

> derived/ に根拠付き要約を作る案を見せてください。対象は 2026-04-01 から 2027-03-31 の experiences/ と projects/ の実記録です。examples/ と templates/ は除外し、各項目に根拠ファイルへのリンクを付け、根拠が足りない項目は「判断できない」としてください。本人の言葉は原文のまま引用してください。

> questions.md から、状態が「途中」か「お休み」の問いを一覧にし、それぞれの最後の記録へのリンクを付けてください。続けるかどうかの判断はしないでください。
