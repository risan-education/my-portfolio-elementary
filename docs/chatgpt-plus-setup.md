# ChatGPT Plusを契約して使う場合の初期設定

- 作成日: 2026-09-26
- 更新日: 2026-09-26

このページでは、保護者が **ChatGPT Plusに含まれるCodex** を使い、自分用のGitHubリポジトリを編集する方法を説明します。Codexは、指示を受けてファイルの変更を進めるOpenAIのサービスです。ブラウザーから使う手順に絞ります。

## 1. ChatGPT Plusを契約する

1. [ChatGPT](https://chatgpt.com/)を開き、保護者のアカウントで登録・ログインします。
2. アカウントのプラン変更画面で **Plus** を選びます。入口が見つからない場合は、[公式プラン案内のGet Plus](https://learn.chatgpt.com/docs/pricing)から進みます。
3. 表示される料金・請求周期・条件を確認し、保護者本人が支払い手続きを完了します。
4. アカウントのプラン表示がPlusになっていることを確認します。

PlusでCodexを利用できますが利用枠があります。価格・利用可能な機能・追加購入の条件は公式ページと契約画面で確認してください。この手順ではAPIキーの作成を求めません。[公式のプラン説明](https://learn.chatgpt.com/docs/pricing)

## 2. 自分用のPrivateリポジトリを作る

[はじめ方](getting-started.md)に従い、例えば `family-learning-notes` をPrivateで作ります。配布元 `risan-education/my-portfolio-elementary` への接続を、本人の記録の保存先にしないでください。

## 3. CodexをGitHubにつなぐ

1. [Codex](https://chatgpt.com/codex)を開き、**Plusを契約したChatGPTアカウント**でログインします。
2. GitHub接続の案内から、ノートを所有するGitHubアカウントで認証します。
3. Codexがアクセスするリポジトリを選びます。選択できる場合は対象を絞り、自分用の `family-learning-notes` を許可します。
4. Codexの環境設定で、自分用リポジトリを選んで環境を作成します。環境とは、そのリポジトリのファイルを編集するための作業場所です。
5. この教材はMarkdown中心なので、教材のための追加パッケージ・APIキー・秘密情報の登録は不要です。

接続先と権限を確認したうえで保護者が許可します。画面は変更される場合があります。[公式のCodex cloud初期設定](https://learn.chatgpt.com/docs/cloud)

## 4. 最初の編集を依頼する

作った環境を選び、まず次のように依頼します。

> このリポジトリのAGENTS.mdを読み、作成日・更新日と本人の発言の扱いを説明してください。まだ記録は追加しないでください。

ルールを確認できたら、[AIガイドの依頼例](ai-guide.md)を使って原メモを渡します。「保存先」「実際の体験日」「本人の発言」を明記します。

通常のChatGPTチャットで文章案を受け取っただけでは、GitHubのファイルが更新されたとは限りません。この手順では、リポジトリを選択したCodexの作業結果として変更ファイルが出ているかを確認します。
Codexは [AGENTS.mdを指示として参照](https://learn.chatgpt.com/docs/agent-configuration/agents-md)します。通常チャットで下書きだけを頼む場合は指示書も添付し、完成した文章は自分で保存します。

## 5. 編集結果を確認して反映する

1. Codexの結果で変更ファイルと差分（変更前後の違い）を開きます。
2. 作成日・更新日、本人の言葉、保護者の観察、原メモを確認します。
3. 内容がよければ **Create pull request** などからプルリクエスト（変更を取り込むための提案）を作ります。
4. GitHubでその提案を開き、対象が**自分用のPrivateリポジトリのmain**であることを確認します。
5. 変更内容を確認して **Merge pull request → Confirm merge** で取り込みます。競合や取り込み不可の表示がある場合は、先に原因を確認します。
6. リポジトリのmainを開き、ファイルが反映されていれば完了です。

Codexが作業を終えた時点と、mainへの反映完了は区別します。未反映の提案が残っている間に同じ記録を別の場所で編集すると、変更がぶつかりやすくなります。

## 困ったとき

- リポジトリが見えない: GitHub接続で自分用リポジトリを許可したか、正しいGitHubアカウントかを確認します。
- 組織の許可待ち: 組織の管理者による承認が必要な場合があります。自分用の保存先と接続先を確認します。
- Plusなのに利用できない: Plusを契約したアカウントか、利用枠・対象機能の表示を確認します。
- 日付が入らない: AGENTS.mdが自分用リポジトリにもあるか確認し、[日付のルール](file-dates.md)を明示して再編集を頼みます。
