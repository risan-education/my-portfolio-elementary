# ChatGPT Plusを契約して使う場合の初期設定

- 作成日: 2026-09-26
- 更新日: 2026-09-26

**WindowsまたはMacのChatGPTアプリから、GitHubプラグインで自分用のノートを直接読み書きする**手順です。

必要なのは、対象リポジトリのファイルを作成・更新できるGitHub接続です。利用できる機能はアプリ・アカウント・接続の種類によって異なるため、手順4で実際の対応状況を確認します。**ChatGPT Plusの契約後、必ずGitHubへの接続設定を行ってください。**

## 最初にすることの流れ

1. **ChatGPTにGoogleアカウントで新規登録する。** すでにChatGPTのアカウントがある方は、そのアカウントでログインします。
2. **ChatGPT Plusを契約する。** 料金と契約内容を確認します。
3. **パソコン（またはスマホ）にChatGPTアプリをインストールする。** Plusを契約したアカウントでログインします。
4. **ChatGPTが自分のGitHubに接続できるようにする。** 自分用のPrivateリポジトリを用意し、GitHubへの接続とアクセス権を設定します。
5. **ChatGPTからGitHubを操作する。** 記録の作成・編集を依頼し、内容を確認してmainへ直接保存します。

以下は主にWindows・Macの画面を想定した説明です。スマホで利用する場合も、GitHub接続とファイルの作成・更新がその環境で利用できるかを確認してから進めます。

## 1. ChatGPT Plusを契約する

1. [ChatGPT](https://chatgpt.com/)で保護者のアカウントに登録・ログインします。**Googleアカウントでの登録がおすすめです。** すでにアカウントがある方は、これまで使っていた方法でログインしてください。
2. プラン変更画面でPlusを選びます。入口が見つからない場合は[公式プラン案内](https://learn.chatgpt.com/docs/pricing)から進みます。
3. 料金・請求周期・条件を確認し、保護者本人が支払い手続きを完了します。
4. パソコン（Windows・Mac）またはスマホに公式ChatGPTアプリをインストールし、Plusを契約した同じアカウントでログインします。

料金・利用枠は契約画面で確認してください。この手順のためにAPIキーを発行する必要はありません。

## 2. 自分用のPrivateリポジトリを作る

[はじめ方](getting-started.md)に従い、例えば `family-learning-notes` をPrivateで作ります。

GitHubで自分用のトップページを開き、URLをコピーします。例えば `https://github.com/自分のユーザー名/family-learning-notes` という形です。配布元のURLではなく、**自分が作ったノートのURL**を使います。

## 3. ChatGPTアプリからGitHubに接続する

Windows・Macとも、次の流れで設定します。画面の名称や配置はアプリのバージョンによって異なります。

1. ChatGPTアプリの **Plugins（プラグイン）** を開きます。
2. **GitHub** を検索し、提供元と説明・利用可能な操作を確認してインストールします。
3. 接続の案内が出たら、ノートを所有するGitHubアカウントでログインします。インストール時ではなく、最初の利用時に認証を求められる場合もあります。
4. GitHub側で対象を選択できる場合は、自分用の `family-learning-notes` にアクセスを限定します。ファイルを編集するための書き込み権限を含め、表示された権限を確認して接続します。
5. ChatGPTで新しい会話を開き、GitHubプラグインを指定するか、「GitHubプラグインを使って」と依頼します。

接続先は自分用のPrivateリポジトリです。個人利用のために、配布元の組織への参加を申請する必要はありません。
[公式のプラグイン導入手順](https://learn.chatgpt.com/docs/plugins)

## 4. 読み書きできるか確認する

コピーしたURLを添えて、次のように依頼します。

> GitHubプラグインを使って、このリポジトリに接続してください。
>
> 対象: ここに自分用リポジトリのURLを貼る
>
> mainのREADME.mdとAGENTS.mdを読んでください。Privateであることと、利用できるツールでmainのファイルを直接作成・更新できるか確認してください。まだ書き込みはしないでください。読み取りだけの場合は、そのことを説明してください。

**リポジトリを読めることと、書き込めることは別です。** GitHubへの接続ができても、参照・検索しかできない接続では直接編集できません。「接続済み」という表示だけで完了とせず、実際に提供される作成・更新機能と対象への権限を確認します。

読み書き可能と確認できたら、[AIガイドの依頼例](ai-guide.md)で原メモを渡し、「まず保存前の文章を見せて」と頼みます。ChatGPTが指示書を自動で読むとは限らないため、毎回必要に応じてAGENTS.mdを読むよう指定してください。

## 5. 内容を確認してmainに直接保存する

本人の言葉・原メモ・作成日・更新日を確認し、内容がよければ次のように依頼します。

> 内容を確認しました。GitHubプラグインを使い、この内容を私のリポジトリのmainに直接保存してください。新しいブランチやpull requestは作らないでください。既存ファイルは最新の内容を読み直し、他の変更を消さずに更新してください。保存後にファイルを読み直して確認し、ファイルのURLとコミットを教えてください。

GitHubでリンク先を開き、mainのファイルと日付を確認できれば完了です。

この方法では、接続ツールがGitHub上のファイルを直接更新してコミットを作ります。パソコンでgit pushコマンドを打つ操作は不要です。結果は「mainに直接保存」となり、プルリクエストの作成・マージは行いません。

文章案が返っただけなら未保存です。「保存できなかった」と出た場合も完了とはせず、理由を確認します。

## 困ったとき

- **PluginsやGitHubが見つからない**: アプリの更新と、アカウントでの提供状況を確認します。「Apps（アプリ）」など別の接続画面が表示される場合も、名称だけで同じ機能だと判断せず、ファイル更新に対応しているか確認します。
- **読み取りしかできない**: この接続では手順5を実行できません。書き込み対応のGitHubプラグインが利用可能か確認し、提供されていなければ本文の下書きまで行い、[GitHubでの手動保存](getting-started.md)を使います。
- **一覧にノートが出ない**: GitHubで許可したアカウント・リポジトリを確認します。URLを直接指定して読めるか試す方法もあります。
- **mainへの保存が拒否される**: 書き込み権限やブランチ保護が原因の場合があります。保護設定を自動で解除させず、拒否の理由を確認します。
- **ファイルが変わらない**: 保存先・ブランチ・コミット・保存後の再読み取り結果を確認します。
- **日付が入らない**: [日付のルール](file-dates.md)とAGENTS.mdを読み、修正するよう依頼します。
