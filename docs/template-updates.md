# テンプレートを更新する

- 作成日: 2026-09-26
- 更新日: 2026-09-26

テンプレートを複製しても、配布元の変更は自動で入りません。現在の配布版は[VERSION](../VERSION)、内容は[変更履歴](../CHANGELOG.md)で確認できます。

## 自分の記録を残したまま更新する

1. [控えと復元の確認](backup-and-restore.md)を行う。
2. 配布元の変更履歴を読み、今使っている版との差を確認する。
3. AIに「自分の記録と追加ルールを残して、テンプレートの更新案を見せて」と頼む。
4. 原則としてAGENTS.md、CLAUDE.md、.github/copilot-instructions.md、templates/、docs/を比較する。自分で追加した内容は残し、必要な変更だけ選ぶ。
5. examples/の追加例は本人の実記録に混ぜない。experiences/、projects/、questions.md、profile/、derived/など本人の記録を配布元の空欄で上書きしない。
6. 差分とリンクを確認して保存する。適用した版と日付を家庭内の更新メモに残す。全変更を適用した場合だけVERSIONを配布版にそろえる。

配布元の履歴をそのまま取り込むmerge、強制push、フォルダごとの置換を初心者向け手順にはしません。古い版でも記録を続けられます。

## 配布元の管理者向け

新しい版では、変更点と未検証事項をCHANGELOG.mdに記録します。公開前に scripts/check-docs.ps1 を実行し、[接続確認](connection-check.md)の実機結果とは区別します。
