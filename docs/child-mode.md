# 本人モード: 保護者が子どもの言葉を取り次いで記録する

- 作成日: 2026-10-02
- 更新日: 2026-10-02

**子どもは保護者に話し、保護者がChatGPTに入力します。** ChatGPTは保護者が読み上げやすい短い質問を返します。本人の言葉を中心に残す使い方を、この教材では「本人モード」と呼びます。ChatGPTの公式機能名ではなく、指示書で決めた呼び方です。

## 始める前に（初回）

保護者が[初期設定](getting-started.md)を済ませ、本人用Private・AGENTS.mdの読み取り・mainへの保存と再読み取りを確認します。本人と残してよい範囲を相談し、メモリとデータ利用の設定も確認します。

OpenAIは、13歳未満の教育利用では大人が実際のChatGPTとのやり取りを行うよう案内しています。保護者のアカウントを渡して、子どもが直接入力・音声対話する手順にはしません。保護者が質問を伝え、子どもが話した言葉を取り次ぎます。[公式の年齢案内](https://help.openai.com/en/articles/8313401-is-chatgpt-safe-for-all-ages)（確認日: 2026-10-02）

## 始め方

1. 保護者が、準備済みの会話で次の一言を送ります。開始は、その会話で作る記録を終了時に保存する依頼も兼ねます。毎回同じ確認は求めません。

   ```text
   本人モードで
   ```

2. ChatGPTの質問を保護者が確かめて子どもに伝えます。回答は「」で囲んでそのまま入力します。保護者自身の補足は「」の外に書きます。
3. 保護者が「おわり」と送るか、質問の上限に達すると、条件を確認済みの保存先へ保存します。「保存しない」「残したくない」と伝えられた場合は保存しません。
4. 保存後はファイルのリンクとコミットを開いて確認します。案だけ返された場合や保存に失敗した場合は未保存です。
5. 本人モードは続くため、保護者向けの話し方に戻すときは「親モードにして」と送ります。「よんで」は閲覧として扱い、取り下げの希望もそのまま伝えられます。

やり取りは[例01](../examples/prompts/01-first-quick-note.md)の折りたたみ「本人モード」を参照してください。学年を毎回伝える必要はありません。

## 質問は短く、一度に一つ

| 聞く目的 | 質問の例（必要なものだけ） |
| --- | --- |
| きっかけを聞く | きょう、なにをみつけた？ |
| 見たことを聞く | どこでみつけた？ |
| 考えを聞く | どうしてだとおもう？ |
| 次の希望を聞く | つぎはなにをしたい？ |

すでに話した段階は飛ばし、短い一言や低学年では1〜2問、全体で4問までを目安にします。「わからない」「いわない」を受け入れ、「もう十分」で終われます。全段階を埋める必要はありません。

「おしえて」と伝えられたら、保護者が子どもに伝えられる短い説明を返します。不確かなことは断定せず、使った資料の出典を記録します。反応を聞く場合も質問の上限に含めます。方法の提案は、試すまでは「案・未実施」です。

## できあがる記録

- 記録者は「本人（保護者が代筆）」です。本人が話したことと保護者の補足を分けます。
- 日記は本人の言葉と記録の項目から構成し、末尾に「（本人のことばと記録から AI が構成）」と付けます。一言しかないときは1文でも十分です。
- 入力メモには最初の入力と回答を原文で残します。不要な個人情報や本人が残したくない内容は除きます。
- AIの説明は「AIがおしえたこと」に分けます。AIが質問したことを、本人が発した問いとして台帳に追加しません。
- 新規ファイルは `index.md` に追加し、追記では最終更新を直します。新しい本人の問いがあれば `questions.md` にも追加します。保存先や一覧は[呼び出し方](finding-records.md)を参照してください。

## 設定と保存の確認

子どもの発言を保護者のメモリに残したくない場合は、利用環境のメモリ設定を確認してオフにします。**通常の会話を分けるだけでは、メモリの分離にはなりません。** メモリをオフにしても過去の会話や保存情報の削除とは別です。モデル改善へのデータ利用も別の設定で確認します。[公式のメモリ説明](https://help.openai.com/en/articles/8590148-memory-in-chatgpt)（確認日: 2026-10-02）、[個人情報の扱い](privacy.md)

保護者が音声入力や読み上げを使う場合も、実際の操作・対話は保護者が担い、文字起こしの誤りを確認してから送ります。保存後に誤りが見つかったら訂正日と理由を追記します。

本人用Private・書き込み権限・保存後の再読み取りが確認できない環境では、匿名化した案までを表示します。保護者が保存するまで「ほぞんしたよ」とは言いません。取り下げは[利用範囲と削除](record-choices.md)に沿って扱います。

## プロジェクトや通常の会話に貼る指示

AGENTS.mdが読める場合はそちらを使います。読めない場合は、下の最小限の指示で下書きを作れます。接続や保存機能が利用できることを保証するものではありません。

```text
小学生の記録を、保護者が操作する「本人モード」で作ります。
子どもは保護者に話し、保護者が本人の言葉を「」で囲んで入力します。
保護者が読み上げやすい短い質問を、一度に一つだけ返してください。
すでに分かっていることは聞き直さず、短い記録は1〜2問、合計4問まで。
「わからない」「いわない」を受け入れ、「もう十分」で終えてください。
発言・日付・数値を補わず、本人の言葉、保護者の補足、AIの説明を分けます。
入力は原文で保持し、本人が残したくない内容や不要な個人情報は除きます。
「おわり」で記録を作ります。「保存しない」「残したくない」を優先します。
保存は、本人用Private・mainへの書き込み・保存後の再読み取りを確認できる場合だけ。
記録の用紙と保存手順を確認できない場合は匿名化した下書きまでとし、保存済みとは言わないでください。
AIが出した質問を本人の問いとして登録せず、新規記録はindex.md、本人の新しい問いはquestions.mdにも反映します。
保存後は保護者向けに実際のファイルリンクとコミットを示してください。
「よんで」は閲覧のみ。「親モードにして」で保護者向けの話し方に戻ります。
```

## 未確認のこと

- 利用者の端末・プラン・接続での保存動作、プロジェクト内で使える機能。
- 保護者の音声入力での文字起こし精度。
- 初心者による設定から保存までの通し検証。
