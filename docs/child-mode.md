# 本人モード: 子ども自身がChatGPTと話して記録を作る

- 作成日: 2026-10-02
- 更新日: 2026-10-02

保護者モードに慣れてきたら、「本人モードで」と送るだけで、ChatGPTが子ども本人に話しかけて記録を作ります。子どもが話した言葉がそのまま記録になり、終わると自動で保存されます。保護者は、あとから読み直して追記や訂正を頼めます。

## 始め方

1. いつもの会話（自分用のPrivateリポジトリに接続した状態）で、保護者が次のように送ります。続きの記録なら、記録の名前を添えます。

```text
本人モードで
```

```text
本人モードで。ダンゴムシの記録のつづき
```

2. ChatGPTが子どもに向けて短く話しかけます。子どもは、自分で打つ・音声で話す・保護者に言って代わりに打ってもらう、のどれでも構いません。どれも本人モードです。
3. 子どもか保護者が「おわり」と言うと、ChatGPTが記録を作ってそのまま保存し、「ほぞんしたよ」と伝えます。保護者向けにはファイルのリンクが表示されます。
4. 保存したあとも本人モードは続きます。子どもが続けて話せば、次の記録として聞き始めます。終えるときは保護者が次のように送ります。

```text
親モードにして
```

5. 保護者はあとで記録を開いて読み直します。直したいことがあれば、親モードに戻してから「◯◯の記録に追記」「ここを訂正」と頼みます。

## 本人モードでChatGPTがすること

- 短い文で、1回に1つだけ聞きます。低学年にはひらがな多めで話します。保護者が「2年生です」のように伝えると、それに合わせます。
- 聞く順番は保護者モードと同じ4段階ですが、子ども向けの言葉になります。
  1. きょう、なにをみつけた？ なにがふしぎだった？（課題の設定）
  2. どこで？ どんなふうに？ なにをためした？（情報の収集）
  3. どうしてだとおもう？ まえとちがうところはある？（整理・分析）
  4. だれにはなしたい？ えにかく？ つぎはなにをしたい？（まとめ・表現）
  合計4問までです。「わからない」「いわない」はそのまま受け取って次へ進みます。
- 子どもが「おしえて」と言ったら、子どもに分かる言葉で短く教えます。分からないことは「わからない」と言います。教えた内容は、記録では「AIがおしえたこと」として本人のことばと分けて残り、そのあと「きいて、どうおもった？」と1回だけ聞いて、本人の反応を本人のことばに残します。
- 本名・学校名・住所・友だちの名前は聞きません。子どもが言っても記録には入れません。
- 「すごい」「かしこい」のような評価や、性格の決めつけはしません。
- 10分くらい経ったら「ここまでにする？」と1回聞きます。

## できあがる記録

- 用紙は内容からChatGPTが選びます（一言→ひとこと記録、本→体験の記録、作ったもの→作品カード、ためしたいこと→探究ノート、続き→追記）。
- 記録者は「本人（ChatGPTとの対話）」、保護者が打った場合は「本人（保護者が代筆）」になります。
- 本人のことばは、本人が打った・話した言葉だけです。ChatGPTの質問文は記録に入らず、メモ欄に対話の流れが短く残ります。
- 冒頭の「きょうのこと（にっき）」は、本人の言葉遣いのまま2〜6文にまとめた読みやすい形で、末尾に「（本人のことばと記録から AI が構成）」と付きます。
- 新しい「なんで？」があれば、問いの台帳（questions.md）にも1行足されます。

## 音声で使う（低学年向け）

- ChatGPTの返事を読み上げるには、スマホでは返事を長押しして「読み上げ」、パソコンでは返事の下の読み上げボタンを使います。
- 音声モード（話して返す）が使える環境では、子どもが話すだけで進められます。周りに人がいない場所で使い、名前や学校のことは話さない約束を先にしておきます。
- 聞き取りの誤りがあり得るので、保存後に保護者が本人のことばを読み直し、違っていれば訂正を頼みます。

## 保護者が知っておくこと

- **年齢条件**: ChatGPTは13歳以上が利用条件で、18歳未満は保護者の許可が必要です。小学生本人のアカウントは作れないため、本人モードは保護者のアカウントで行います。規約上、利用の責任は保護者にあります。中学生になって本人のアカウントを持ったら、ChatGPTの保護者機能（アカウント連携、利用時間、音声やメモリのオフ）に切り替えます。
- **文部科学省のガイドライン**: 「初等中等教育段階における生成AIの利活用に関するガイドライン（Ver.2.0）」（2024年12月）は、利用規約の年齢制限と保護者同意の遵守を求め、小学生の直接利用には「より慎重な見極め」を示しています。本教材では、保護者モードで対話を見せる段階を経てから、短時間で試す位置づけにしています。
- **設定**: 子どもの発言が保護者のメモリに残らないよう、ChatGPTのメモリをオフにするか、本人モード用の会話を分けます。モデル改善へのデータ利用の設定は[個人情報の扱い](privacy.md)で確認します。
- **自動保存の意味**: 本人モードでは確認なしで保存されます。あとから読み直し、本人が「残したくない」と言った記録は[利用範囲の見直しと削除](record-choices.md)の手順で扱います。
- **保存できない環境**: ChatGPTがリポジトリに書き込めない環境では、記録案が表示されて「おうちの人にほぞんしてもらってね」と案内されます。その場合は保護者が保存します。

## ChatGPTのプロジェクトに設定する場合

ChatGPTの「プロジェクト」を作り、「指示（Instructions）」に次の文章を貼ると、そのプロジェクト内の会話では毎回この約束が効きます。AGENTS.mdが読めている環境では不要ですが、安定して使いたいときの選択肢です。プロジェクト内でGitHub接続による保存が使えるかは環境によるため、使えない場合は保護者が保存します。

```text
あなたは小学生の「Myポートフォリオ」の聞き役です。この会話は「本人モード」です。
- 子ども本人に向けて、短い文で、1回に1つだけ質問してください。低学年にはひらがな多めで話してください。
- 聞く順番: ①きょう、なにをみつけた？なにがふしぎだった？ ②どこで？どんなふうに？なにをためした？ ③どうしてだとおもう？まえとちがうところはある？ ④だれにはなしたい？えにかく？つぎはなにをしたい？ 合計4問まで。「わからない」はそのまま受け取って次へ。
- 「おしえて」と言われたら、子どもに分かる言葉で短く正確に教え、分からないことは「わからない」と言う。教えたあとに「きいて、どうおもった？」と1回聞く。
- 本名・学校名・住所・友だちの名前は聞かない。言われても記録に入れない。評価やほめすぎ、性格の決めつけはしない。
- 保護者が子どもの言葉を代わりに打つこともある。「」の中は本人の言葉として扱う。
- 「親モードにして」と言われるまで本人モードを続ける。「おわり」と言われたら、本人が言った言葉だけを「」のまま並べた記録を作る。AIが教えたことは「AIがおしえたこと」として分ける。質問文は記録に入れない。記録者は「本人（ChatGPTとの対話）」または「本人（保護者が代筆）」。
- 記録を保存できる接続があれば、確認を待たずに保存して「ほぞんしたよ」と伝え、保護者向けにファイルのリンクを示す。保存できなければ記録を表示して「おうちの人にほぞんしてもらってね」と伝える。
```

## AGENTS.mdが読めていないときのコピペ用

接続していない通常のChatGPTで試すときは、上の文章をそのまま会話の最初に貼り、そのあとに「本人モードで」と送ります。保存は保護者が行います。
