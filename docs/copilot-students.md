# 中学生とCopilotの無料利用

- 作成日: 2026-09-26
- 更新日: 2026-09-26

**中学生なら全員が自動的に学生向け無料プランになるわけではありません。** 一般向けのCopilot Freeと、学生認証が必要なCopilot Studentは別のプランです。

| 状況 | 利用の考え方 |
| --- | --- |
| 12歳の中学生 | GitHubの最低年齢13歳を満たさないため、本人のGitHubアカウントでは始められません。この教材は保護者自身が操作します。 |
| 13歳以上で、学生認証をしていない | 利用資格を満たせばCopilot Freeの無料枠で試せます。 |
| 13歳以上で、GitHub Educationに学生として認証された | Copilot Studentを有効化すると、学生向けの無料枠を利用できます。 |
| 保護者が操作する | 保護者自身のFree・有料プラン等を使います。子どもの学生資格を保護者の契約に適用する前提にはしません。 |

無料プランにも利用枠と機能の制限があります。Copilot Studentは有料プランと全く同じ内容ではありません。[公式プラン比較](https://docs.github.com/en/copilot/get-started/plans)

## 学生向け無料プランの条件

GitHub Educationの申請には、13歳以上、本人のGitHub個人アカウント、対象となる学校・教育課程への在籍とその証明が必要です。
公式ページは高校・大学・ホームスクール等を例示していますが、日本の中学校すべての適格性を保証してはいません。**中学生の場合も年齢だけで判断せず、自分の学校・在籍状況が認証されるか申請で確認します。**

証明書類の例は、現在の在籍日が確認できる学生証、時間割、成績証明、在籍証明などです。学校メールを求められる場合もあります。学校がメールを発行していない場合の説明書類についても公式案内があります。
[学生認証の申請条件と書類](https://docs.github.com/en/education/about-github-education/github-education-for-students/apply-to-github-education-as-a-student)

## 申請の流れ

1. 13歳以上の本人が、保護者と相談して自分のGitHubアカウントを準備します。
2. [Education benefits](https://github.com/settings/education/benefits)を開き、**Start an application**から申請します。
3. 画面で指定された在籍情報と証明を提出します。証明書は公式の申請画面にだけ提出し、学習ノートや公開Issueに保存しません。
4. 承認後、Education benefitsの学生・教員向け特典から **Learn more** を開き、Copilot Studentの有効化へ進みます。
5. Copilotの設定画面でStudentが有効になっていることを確認します。

学生認証の承認とCopilotの有効化は別の段階です。反映まで数日かかる場合があり、資格も再確認されます。無料特典を使うつもりなのに支払い画面が出た場合は、契約を進める前に公式の案内を確認します。
[学生向けCopilotの有効化と困ったときの手順](https://docs.github.com/en/copilot/how-tos/copilot-on-github/set-up-copilot/enable-copilot/set-up-for-students)

## 「話しかけるだけ」で編集できる？

初期設定後、VS CodeのCopilotエージェントには自然な文章でファイルの作成・編集を頼めます。例えば「この原メモを体験記録にして、作成日と更新日も入れて」と依頼できます。
ただし、初回のインストール・ログイン・ノートの取得は必要です。毎回の内容確認とGitHubへの保存も行います。音声入力そのものの有無は利用環境によるため、この教材では文字入力を基本にします。
[VS Codeの公式エージェント入門](https://code.visualstudio.com/docs/agents/agents-tutorial)

この小学生版では、引き続き保護者が操作します。中学生本人が使い始めるときは、本人のアカウントとアクセス権を別途整えてください。
