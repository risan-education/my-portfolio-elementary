## レビューと実施内容

- 最初の依頼でmainを9fba408までfast-forwardした。改善作業の開始時にもmainが最新で、未コミット変更がないことを確認した。
- 例01〜05をレビューし、本人が言っていない問い、未確認の撮影日・材料・命名者、概数の欠落、原文メモの要約、問いの台帳の前提の食い違いを指摘した。
- 5例の内容を修正。最初に短いメモと日記の見本を置き、詳しい対話・保存用Markdown・本人モードを折りたたみにした。入力メモは原文を保持し、質問を一度に一つに整理した。
- 例06〜09に、一言だけで終える、保存した記録を読む、考えの変化をふりかえる、利用停止・削除を依頼する例を追加した。すべて明示的な架空例で、実記録の一覧へは登録していない。
- 本人モードを、保護者がChatGPTの操作・対話を担って本人の言葉を取り次ぐ方式へ統一した。終了時保存は確認済みの本人用Privateに限定し、保存しない意思を優先する。
- 公式の年齢案内・メモリ説明を再確認し、本人モードの案内を訂正。過去の調査メモは保持して訂正を追記した。
- READMEの入口を整理し、導入手順を接続能力・保存方法の確認から始める順に変更した。用紙、AI向け指示、記録一覧・検索・削除の説明を整合させた。
- 配布元の保守作業で毎回 /save-prompt を適用する指示をAGENTS.mdとCopilot向け指示にも記載した。家庭の記録案を無断保存するルールにはしていない。
- VERSION・README・CHANGELOGを0.4.1にそろえた。
