# 話しかけ方と、できあがる記録の例（すべて架空）

- 作成日: 2026-10-01
- 更新日: 2026-10-02

**まずは送るメモと、できあがる文章だけを見てください。** 詳しい対話と保存用Markdownは折りたたんであります。記録を作るだけでなく、読む・ふりかえる・取り下げるまでの9例です。

発言・日付・活動はすべて架空です。本人の活動一覧・年間集計・分析には含めません。自分の記録として使うときは実際の内容に置き換えます。架空のまま練習するときは examples/ 内に保存し、index.md・questions.md には登録しません。

## 使い方

1. 保護者が[初期設定](../../docs/getting-started.md)と[接続確認](../../docs/connection-check.md)を済ませます。新しい会話では自分用PrivateのURLを添えて「AGENTS.mdを読んで、記録を始める準備をしてください」と送ります。
2. 例の「送るメモ」を、活動日・やったこと・本人が実際に言った言葉に置き換えます。本人の発言は「」で囲み、保護者の返事や本の引用は誰の言葉か明示します。
3. 案を子どもと読み直します。質問は一度に一つ、合計4問までで、短い一言なら1〜2問。「質問は不要」「もう十分」でも構いません。
4. よければ「この内容で保存してください」と送ります。mainのファイルリンクを開き、本文と日付を確認します。案の表示だけでは未保存です。

例01〜05の末尾には、[本人モード](../../docs/child-mode.md)での別の進め方もあります。保護者がChatGPTを操作し、質問を子どもに伝えて回答を取り次ぎます。保護者モードと本人モードの両方を同じ名前で新規保存する想定ではありません。同名ファイルがある場合は、追記か別記録かを確認します。

文章の表現が例と違っていても構いません。本人の発言と入力メモの原文、未確認の情報、保存先が正確であることを優先します。作成日・更新日は架空の実行日として記載しており、実際には記録を作る日・編集する日を使います。
