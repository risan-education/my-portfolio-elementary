## 使い方

1. 保護者が[初期設定](../../docs/getting-started.md)と[接続確認](../../docs/connection-check.md)を済ませます。
2. 本人用PrivateのURLを添え、「AGENTS.mdを読んで、記録を始める準備をしてください」と送ります。
3. メモを実際の内容に置き換えます。本人の発言は「」で囲みます。質問は一度に一つ。「質問は不要」「もう十分」でも構いません。
4. 案を読み直し、「この内容で保存してください」と送ります。mainのリンクを開いて確認します。

例01〜05には、保護者が子どもの言葉を取り次ぐ[本人モード](../../docs/child-mode.md)の別案もあります。どちらか一方を使います。

用紙内の日付とリンクは記入見本です。作成日・更新日は実際の編集日、根拠リンクは本人用Privateの原記録に合わせます。練習はexamples/内で行い、本人のindex.md・questions.mdや集計には含めません。
