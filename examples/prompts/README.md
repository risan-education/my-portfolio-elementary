# ChatGPTへの話しかけ方と、できあがる記録の例（すべて架空）

- 作成日: 2026-10-01
- 更新日: 2026-10-02

「ポートフォリオを作ると言われても、何から始めればいいかわからない」という保護者向けに、**ChatGPTに送る文章（プロンプト）と、ChatGPTが返す記録の案**をセットで示します。全部で30例ほどを予定し、まず5例を用意しました。

ここにある子どもの発言・日付・活動はすべて架空です。実在する子どもの記録ではなく、本人の活動一覧や年間集計、AIの分析対象には含めません。例の文章をそのまま自分の子どもの記録にしないでください。

## 使い方

1. 気になる例を開き、「ChatGPTに送る文章」をコピーします。
2. 日付・やったこと・本人のことばを、自分の子どもの実際の内容に置き換えて ChatGPT に送ります。本人の言葉は「」で囲みます。覚えていない部分は書かないか「わからない」と書き、作り足しません。「本人の言葉を足さないで」「日付は合っています」などの決まり文句は要りません。指示書（AGENTS.md）が既定で守ります。
3. ChatGPT は文章案のあとに「足せるとよさそうなこと」を、探究の4段階（課題の設定→情報の収集→整理・分析→まとめ・表現）の順に1つずつ聞きます（合計4問まで）。答えられるものだけ答え、聞いていないことは「聞いていない」と返します。「もう十分です」と送れば、そこで文章案がまとまります。
4. 返ってきた案を子どもと読み直し、本人が言っていない言葉が増えていないかを確かめます。
5. よければ「この内容で保存してください。」と送ります。接続の設定は[はじめ方](../../docs/getting-started.md)、確認のポイントは[AIに整理を頼むとき](../../docs/ai-guide.md)にあります。

どの例の記録案も、冒頭に人が読みやすい「きょうのこと（にっき）」（探究ノートは「探究日記」）が付きます。どの例も、質問と答えの往復をそのまま載せています。各例の最後には、同じ場面を「本人モード」（子ども本人がChatGPTと話す。[説明](../../docs/child-mode.md)）でやった場合の往復も付けています。ChatGPTの返事は毎回少しずつ違います。例と一字一句同じになる必要はなく、用紙の項目がそろい、本人の言葉が原文のまま残っていれば十分です。
