# ChatGPTへの話しかけ方と、できあがる記録の例（すべて架空）

- 作成日: 2026-10-01
- 更新日: 2026-10-01

「ポートフォリオを作ると言われても、何から始めればいいかわからない」という保護者向けに、**ChatGPTに送る文章（プロンプト）と、ChatGPTが返す記録の案**をセットで示します。全部で30例ほどを予定し、まず5例を用意しました。

ここにある子どもの発言・日付・活動はすべて架空です。実在する子どもの記録ではなく、本人の活動一覧や年間集計、AIの分析対象には含めません。例の文章をそのまま自分の子どもの記録にしないでください。

## 使い方

1. 気になる例を開き、「ChatGPTに送る文章」をコピーします。
2. 日付・やったこと・本人のことばを、自分の子どもの実際の内容に置き換えて ChatGPT に送ります。覚えていない部分は「未確認」と書き、作り足しません。
3. 返ってきた案を子どもと読み直し、本人が言っていない言葉が増えていないかを確かめます。
4. よければ「この内容で保存してください。」と送ります。接続の設定は[はじめ方](../../docs/getting-started.md)、確認のポイントは[AIに整理を頼むとき](../../docs/ai-guide.md)にあります。

ChatGPTの返事は毎回少しずつ違います。例と一字一句同じになる必要はなく、用紙の項目がそろい、本人の言葉が原文のまま残っていれば十分です。
