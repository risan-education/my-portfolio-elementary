# 例05: 「なんで？」が続いたので探究ノートに進む（架空）

- 作成日: 2026-10-01

## こんなとき

4〜6年生。[例01](01-first-quick-note.md)と[例03](03-add-next-day.md)のようにダンゴムシの記録が2件たまり、本人が「石の下にいるのはなんで？」と聞き続けている。調べたり試したりするなら「探究ノート」に進みます。まだ何もしていない段階で作って構いません。

## ChatGPTに送る文章（コピーして、自分の内容に置き換える）

```text
探究ノートの案を作ってください。きっかけは experiences/261003-dangomushi.md です。
本人が「石の下にいるのはなんで？」「くらいところがすきなんだと思う」「明るいところと暗いところ、どっちに行くかためしたい」と言っています。
まだ何も試していません。方法はこれから本人と決めます。
用意するものや安全の注意は、案として出してもらって構いませんが、未実施と分かるようにしてください。
状態は「これから」にしてください。
```

## ChatGPTが返す案（架空例）

> 保存先: `projects/261015-dangomushi-inquiry.md`（探究ノートの用紙）
>
> 「1. 問い」と「2. 予想」は本人の発言だけで書きました。「3. 方法」は本人の発言「どっちに行くかためしたい」をもとに、用意するものと安全の注意を案として足し、未実施と明記しています。「4. やってみた記録」は空欄です。
> `questions.md` の「くらいところがすきなのかな」の行は、状態を「途中」に変え、このノートへのリンクを足す案を下に示します。

## ポイント

- 探究ノートは「答えを出すための用紙」ではなく、「本人がどう考え、何を試し、何が分かって何が分からなかったか」を残す用紙です。実験をしないまま「お休み」になっても構いません。
- 方法を決めるのは本人です。ChatGPTの案はたたき台として本人に見せ、変えたいところは変えます。
- 試したら「4. やってみた記録」に日付付きで足し、結果が予想と違っても書き換えません。
