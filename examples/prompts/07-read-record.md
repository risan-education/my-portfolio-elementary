# 例07: 保存した記録を読み返す（架空）

- 作成日: 2026-10-02
- 更新日: 2026-10-02

[例01](01-first-quick-note.md)の最初の案を保存した後に読み返します。

## 送る一言

```text
10月3日のダンゴムシの記録を見せて
```

## 返ってくる内容の例

index.md から原記録を開きます。候補が複数なら題名と日付を示します。

> 2026-10-03「ダンゴムシが丸くなった」です。
>
> きょう、公園でダンゴムシを見つけた。指でつつくたびに丸くなるのを、3回くらい繰り返していた。「まるくなった！」「なんでまるくなるの？」と言った。
>
> （本人のことばと記録から AI が構成）

実際の返答には、確認したmainのファイルへのリンクと、日記以降の本文も付けます。この「きょう」は記録当日の表現で、読んでいる日を指しません。

## ほかの探し方

| 送る一言 | 確認する情報 |
| --- | --- |
| 10月に体験したことを見せて | index.md と原記録の活動日 |
| 10月に保存した記録を見せて | 原記録の作成日。活動日とは区別する |
| 探究ノートで「途中」のものを見せて | 候補の探究ノートを開いて状態を確認する |
| まえのだんごむしのきろく、よんで | 保護者が伝えた依頼に対し、日記を読み上げやすく返す |

見つからなければ、その旨を返します。閲覧だけでは保存しません。

詳しくは[記録の保存先・一覧・呼び出し方](../../docs/finding-records.md)を参照してください。
