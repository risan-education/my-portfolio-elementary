# 例07: 保存した記録を読み返す（架空）

- 作成日: 2026-10-02
- 更新日: 2026-10-02

このページはすべて架空です。[例01](01-first-quick-note.md)の最初の案を、追加質問には答えず、本人用Privateに保存済みという設定です。実際には接続先にある記録を読み取り、以下の架空文を検索結果として返しません。

## 送る一言

```text
10月3日のダンゴムシの記録を見せて
```

## 返ってくる内容の例

ChatGPTは index.md とファイル名から候補を探し、原記録を開いて本文を確認します。同じ日・テーマに複数の候補があれば、題名と日付を示して選べるようにします。

> 2026-10-03「ダンゴムシが丸くなった」です。
>
> きょう、公園でダンゴムシを見つけた。指でつつくたびに丸くなるのを、3回くらい繰り返していた。「まるくなった！」「なんでまるくなるの？」と言った。
>
> （本人のことばと記録から AI が構成）

実際の返答には、確認したmainのファイルへのリンクと、日記以降の本文も付けます。この「きょう」は記録当日の表現で、読んでいる日を指しません。

## ほかの探し方

| 送る一言 | 確認する情報 |
| --- | --- |
| 10月に体験したことを見せて | index.md と原記録の活動日 |
| 10月に保存した記録を見せて | 原記録の作成日。活動日とは区別する |
| 探究ノートで「途中」のものを見せて | 候補の探究ノートを開いて状態を確認する |
| まえのだんごむしのきろく、よんで | 保護者が伝えた依頼に対し、日記を読み上げやすく返す |

見つからない場合は「見つかりませんでした」と返します。examples/やtemplates/を本人の記録として代用しません。閲覧では作成日・更新日・index.mdを変更せず、保存やコミットもしません。

詳しくは[記録の保存先・一覧・呼び出し方](../../docs/finding-records.md)を参照してください。
