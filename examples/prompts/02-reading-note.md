# 例02: 図書館で借りた本の感想を残す（架空）

- 作成日: 2026-10-01
- 更新日: 2026-10-01

## こんなとき

図書館で借りた恐竜の図鑑を、寝る前に何度も開いている。感想文を書かせたいわけではなく、どのページを見て何を言ったかを残したい。本の感想は「体験の記録」の用紙で、種類を「読書」にします。

## ChatGPTに送る文章（コピーして、自分の内容に置き換える）

```text
記録の案を作ってください。種類は読書です。
2026年10月5日ごろから、図書館で借りた恐竜の図鑑を毎晩見ています。
今日（10月8日）、ティラノサウルスのページを見ながら「前の手がちっちゃい」「なんでこんなにちっちゃいの？」と言いました。
私は「本当だね」と答えただけで、理由は調べていません。
本の正式な題名と著者はあとで確認して足します。今は「恐竜の図鑑（図書館で借りた本）」としてください。
活動日は10月8日にしてください。
```

## ChatGPTが返す案（架空例）

> 保存先: `experiences/261008-dinosaur-book.md`（体験の記録の用紙、種類: 読書）
>
> 本の題名と著者は「未確認」のままにし、「本・資料・作品へのリンク」にあとから書き足せる形にしました。理由を調べていないことも、そのまま残しています。

- 「次にしたいこと」の提案が「未実施」と書かれているか。本人が選んだことになっていないか。
- 書名が「未確認」のままで、勝手に補われていないか。
- 本人のことばが2つだけか。

```text

```

## ポイント

- 「理由は調べていない」も記録です。あとで調べたら、追記として日付付きで足します（[例03](03-add-next-day.md)）。
- 書名・著者は、本の奥付を見てから「追記・訂正」に書き足せば十分です。ChatGPTに書名を推測させないでください。
- 感想を「おもしろかった」などに言い換えないよう、本人の言葉だけを送ります。
