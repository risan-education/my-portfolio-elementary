# 例04: 段ボール工作を写真といっしょに残す（架空）

- 作成日: 2026-10-01
- 更新日: 2026-10-01

## こんなとき

休みの日に段ボールでロボットを作った。そのうち壊れるか捨てることになるので、写真と本人の一言を残したい。写真はスマホにあり、GitHubには上げたくない。作品は「作品カード」の用紙に、写真は所在メモで残します。

## ChatGPTに送る文章（コピーして、自分の内容に置き換える）

```text
作品カードの案を作ってください。
2026年10月11日と12日の2日間で、段ボールでロボットを作りました。名前は本人が「ダンボロボ」と付けました。
本人がやったこと: 箱を選ぶ、腕の形を決める、色をぬる。
私が手伝ったこと: カッターで切る、ガムテープで固定する。
本人のことば: 「うでがうごくようにしたかったけど、むり」「つぎはあしもつける」
うまくいかなかったこと: 腕を動かそうとして、ガムテープで固定したら動かなくなった。
写真は私のスマホに2枚あります。GitHubには上げず、所在だけ書いてください。
```

## 確認して保存する

- 「本人がやったこと」と「おとなが手伝ったこと」が混ざっていないか。
- 写真がリポジトリにアップロードされる案になっていないか（所在メモだけでよい）。
- 「作ろうと思ったきっかけ」など、聞いていない項目が「未確認」か空欄のままか。

```text
この内容で保存してください。
```

## ポイント

- うまくいかなかったことは、作品カードの中でいちばん後で役に立つ部分です。「むり」という言葉も、そのまま残します。
- 写真は[個人情報と写真・作品の扱い](../../docs/privacy.md)のとおり、顔や名札が写っていないか確認し、原本は保護者が管理します。小さな控えを `assets/` に置く場合も、ファイル名に本名を入れません。
- 「次に作るなら？」が本人の言葉で残っていると、次に段ボールを見たときの会話の種になります。
