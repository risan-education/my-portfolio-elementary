# 例01: 公園での一言を、はじめて残す（架空）

- 作成日: 2026-10-01
- 更新日: 2026-10-01

## こんなとき

1〜3年生。公園でダンゴムシを見つけて、子どもが何か言った。ノートを開いて書かせるほどではないけれど、消えてしまう前に一言だけ残したい。はじめての記録は、これくらい短くて十分です。

ChatGPTは文章案のあとに「足せるとよさそうなこと」を1つずつ聞きます。低学年の短い記録なので、この例では2問で終わります。質問は探究的な学習の4段階（課題の設定→情報の収集→整理・分析→まとめ・表現）の順ですが、この例では「課題の設定」は本人の「なんで？」で埋まっているので飛ばし、「整理・分析」は低学年なので省いています。

## 1往復目

**保護者 → ChatGPT**（コピーして、自分の内容に置き換える）

```text
記録の案を作ってください。
2026年10月3日、公園でダンゴムシを見つけました。
本人が「まるくなった！」「なんでまるくなるの？」と言いました。
私（保護者）が見ていたのは、指でつつくたびに丸くなるのを3回くらい繰り返していたことです。
日付は10月3日で合っています。本人の言葉は追加しないでください。
```

**ChatGPT → 保護者**（架空例）

> 保存先: `experiences/261003-dangomushi.md`（ひとこと記録の用紙）
>
> 本人の言葉は送っていただいた2つだけを引用しました。まず、今の内容での案です。

```markdown
# ダンゴムシが丸くなった

- 作成日: 2026-10-03
- 更新日: 2026-10-03
- いつ（不明なら未確認）: 2026-10-03
- 書いた人（本人／保護者の代筆）: 保護者の代筆
- やったこと・見たもの: 公園でダンゴムシを見つけた。
- 本人のことば（正確な発言だけ。要約ならそう書く）: 「まるくなった！」「なんでまるくなるの？」
- つぎに気になること: 「なんでまるくなるの？」（本人の発言）
- 保護者の観察（任意）: 指でつつくたびに丸くなるのを、3回くらい繰り返していた。
- メモ（AIで整理する場合は入力をそのまま残す）: 2026年10月3日、公園でダンゴムシを見つけた。「まるくなった！」「なんでまるくなるの？」と言った。指でつつくたびに丸くなるのを3回くらい繰り返していた。
```

> **質問1（情報の収集）**: ダンゴムシは何匹くらい、どんな場所（石の下、葉っぱの下など）で見つけましたか。本人が色や足など、ほかに気づいて口にしたことがあれば、その言葉も教えてください。
>
> 答えられる範囲で大丈夫です。聞いていなければ「聞いていない」と返してください。このまま保存する場合は「この内容で保存してください」と送ってください。

>


**ChatGPT → 保護者**

> 反映しました。質問はここまでです。全文の案は次のとおりです。メモ欄には最初の入力と回答を順に残しました。

```markdown
# ダンゴムシが丸くなった

- 作成日: 2026-10-03
- 更新日: 2026-10-03
```

## 確認して保存する

- 本人のことばが、実際に言ったものだけになっているか（この例では3つと、電話での1つ）。
- 「保護者の観察」に、自分が見たことだけが書かれているか。
- 日付と保存先が合っているか。

よければ次の一文を送ります。

```text
この内容で保存してください。questions.md への追記もお願いします。
```

## ポイント

- 質問は1回に1つです。答えてから次が来るので、子どもに聞き直しながら進められます。途中でやめたいときは「もう十分です」と送れば、その時点の案がまとまります。
- 質問の段階名（課題の設定・情報の収集・整理・分析・まとめ・表現）は、小学校の総合的な学習の時間で使われる探究の流れの家庭向けの言い換えです。保護者が「次はどこを聞けばよいか」に慣れるためのもので、子どもに覚えさせる必要はありません。
- 「なんで？」に答えを教える必要はありません。問いのまま残すのが、この記録の役目です。
- 保護者が見たことは「保護者の観察」、本人が言ったことは「本人のことば」に分かれます。ChatGPTがこの2つを混ぜていたら、直すよう頼みます。
