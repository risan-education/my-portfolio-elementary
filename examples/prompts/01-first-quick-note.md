# 例01: 公園での一言を、はじめて残す（架空）

- 作成日: 2026-10-01
- 更新日: 2026-10-01

## こんなとき

1〜3年生。公園でダンゴムシを見つけて、子どもが何か言った。ノートを開いて書かせるほどではないけれど、消えてしまう前に一言だけ残したい。はじめての記録は、これくらい短くて十分です。

この例では、ChatGPTが文章案といっしょに「足せるとよさそうなこと」を質問し、保護者が答えられる分だけ答えて、案ができあがるまでの往復を示します。質問は探究的な学習の4段階（課題の設定・情報の収集・整理・分析・まとめ・表現）に沿っています。全部に答える必要はありません。

## 1往復目: 保護者がChatGPTに送る文章（コピーして、自分の内容に置き換える）

```text
記録の案を作ってください。
2026年10月3日、公園でダンゴムシを見つけました。
本人が「まるくなった！」「なんでまるくなるの？」と言いました。
私（保護者）が見ていたのは、指でつつくたびに丸くなるのを3回くらい繰り返していたことです。
日付は10月3日で合っています。本人の言葉は追加しないでください。
```

## 1往復目: ChatGPTが返す案と質問（架空例）

> 保存先: `experiences/261003-dangomushi.md`（ひとこと記録の用紙）
>
> 本人の言葉は送っていただいた2つだけを引用しました。まず、今の内容での案です。

```markdown
# ダンゴムシが丸くなった

- 作成日: 2026-10-03
- 更新日: 2026-10-03
- いつ（不明なら未確認）: 2026-10-03
- 書いた人（本人／保護者の代筆）: 保護者の代筆
- やったこと・見たもの: 公園でダンゴムシを見つけた。
- 本人のことば（正確な発言だけ。要約ならそう書く）: 「まるくなった！」「なんでまるくなるの？」
- つぎに気になること: 「なんでまるくなるの？」（本人の発言）
- 保護者の観察（任意）: 指でつつくたびに丸くなるのを、3回くらい繰り返していた。
- メモ（AIで整理する場合は入力をそのまま残す）: 2026年10月3日、公園でダンゴムシを見つけた。「まるくなった！」「なんでまるくなるの？」と言った。指でつつくたびに丸くなるのを3回くらい繰り返していた。
```

> **足せるとよさそうなこと（答えられるものだけで大丈夫です。聞いていないことは「聞いていない」と返してください）**
>
> 1. 課題の設定: 「なんでまるくなるの？」のあとに、本人が自分の予想（「〜だからかな」など）を言っていましたか。
> 2. 情報の収集: ダンゴムシは何匹くらい、どんな場所（石の下、葉っぱの下など）で見つけましたか。本人が色や足など、ほかに気づいて口にしたことはありますか。
> 3. 整理・分析: 丸くなるものと丸くならないものを比べたり、「〜だから」と理由を言ったりしていましたか。
> 4. まとめ・表現: 家に帰ってから、誰かに話したり、絵に描いたりしましたか。
>
> このまま保存してもよい場合は「この内容で保存してください」と送ってください。

## 2往復目: 保護者が答える（架空例）

本人に聞き直してから返事をしても構いません。この例では、2と4だけ答えられました。

```text
1. 予想は言っていません。
2. 石の下に3匹くらいいました。本人は「足がいっぱい」とも言っていました。
3. 比べてはいません。聞いていません。
4. 帰ってから、祖母に電話で「ダンゴムシがまるくなった」と話しました。絵は描いていません。
```

## 2往復目: ChatGPTが返す改訂案（架空例）

> 答えていただいた2と4を反映しました。1と3は空欄のままにしています。「足がいっぱい」は本人の発言として追加し、メモ欄には最初の入力と今回の回答を順に残しました。

```markdown
# ダンゴムシが丸くなった

- 作成日: 2026-10-03
- 更新日: 2026-10-03
- いつ（不明なら未確認）: 2026-10-03
- 書いた人（本人／保護者の代筆）: 保護者の代筆
- やったこと・見たもの: 公園の石の下でダンゴムシを3匹くらい見つけた。帰ってから祖母に電話で話した。
- 本人のことば（正確な発言だけ。要約ならそう書く）: 「まるくなった！」「なんでまるくなるの？」「足がいっぱい」。祖母への電話で「ダンゴムシがまるくなった」。
- つぎに気になること: 「なんでまるくなるの？」（本人の発言。予想は未確認）
- 保護者の観察（任意）: 指でつつくたびに丸くなるのを、3回くらい繰り返していた。
- メモ（AIで整理する場合は入力をそのまま残す）: 2026年10月3日、公園でダンゴムシを見つけた。「まるくなった！」「なんでまるくなるの？」と言った。指でつつくたびに丸くなるのを3回くらい繰り返していた。（回答）予想は言っていない。石の下に3匹くらい。「足がいっぱい」とも言った。比べてはいない。帰ってから祖母に電話で「ダンゴムシがまるくなった」と話した。絵は描いていない。
```

> 本人の問いが含まれるので、`questions.md` に次の1行を足す案もあります。

```text
| 2026-10-03 | 「なんでまるくなるの？」 | 未着手 | [ダンゴムシ](experiences/261003-dangomushi.md) | 石の下に3匹くらい。祖母に電話で話した |
```

## 確認して保存する

- 本人のことばが、実際に言ったものだけになっているか（この例では3つと、電話での1つ）。
- 答えなかった質問の項目が、空欄か「未確認」のままになっているか。
- 「保護者の観察」に、自分が見たことだけが書かれているか。

よければ次の一文を送ります。

```text
この内容で保存してください。questions.md への追記もお願いします。
```

## ポイント

- 質問の4段階は、小学校の総合的な学習の時間で使われる探究の流れ（課題の設定→情報の収集→整理・分析→まとめ・表現）の家庭向けの言い換えです。保護者が「次はどこを聞けばよいか」に慣れるためのもので、子どもに段階を覚えさせる必要はありません。
- 「なんで？」に答えを教える必要はありません。問いのまま残すのが、この記録の役目です。
- 答えなかった質問は、次に同じ場面があったときに聞いてみる材料になります。無理に埋めると、本人が言っていないことが記録に混ざります。
- 保護者が見たことは「保護者の観察」、本人が言ったことは「本人のことば」に分かれます。ChatGPTがこの2つを混ぜていたら、直すよう頼みます。
- 質問がわずらわしいときは「質問は不要です」と送れば、以後は文章案だけが返ります。
