# 例09: 残したくない記録を取り下げる（架空）

- 作成日: 2026-10-02
- 更新日: 2026-10-02

このページはすべて架空です。[例06](06-one-line.md)の記録を保存した後、2026-10-17に本人が取り下げを希望した設定です。実際の取り下げ対象の内容を、例集や公開の作業記録へ転記しません。

## 送る一言

```text
10月16日の月の記録を、本人が「のこしたくない」と言っています。使うのを止めて、削除したいです。
```

## 最初に返す内容の例

> この記録を、以後の要約や提案には使いません。記録本文、index.md、questions.md、派生文書にある関連箇所を確認し、削除の対象をまとめます。内容そのものは返答に引用し直しません。

対象が特定できる場合は、同じことを聞き直しません。削除範囲を確認するために必要な読み取りに限り、取り下げた内容を分析や要約へ再利用しません。

## 対象を確認したあとの案（架空）

| 確認先 | この例で確認できた状態 | 行うこと |
| --- | --- | --- |
| 原記録 | `experiences/261016-moon.md` がある | mainの現在のファイルを削除 |
| index.md | 対応する題名・リンクの行がある | 行を削除 |
| questions.md・派生文書・添付 | この例では関連箇所なし | 変更なし |
| Git履歴 | 過去のコミットに残る | 今回は書き換えない。現在のファイルの削除とは区別 |
| 保護者の端末・バックアップ・AIの会話 | AIからは確認できない | 保護者が確認し、必要な削除を行う |

> 今回は、mainの現在の記録ファイルとindex.mdの対応行を削除する範囲で進めてよいですか。Git履歴や手元のコピーには残るため、完全な削除とはなりません。

## 保護者が範囲を指定する

```text
本人と確認しました。今回は現在のファイルとindex.mdの行を削除してください。Git履歴は変更しません。手元のコピーとAIの会話は私が確認します。
```

この指定があれば、同じ許可を再度求めずに実行します。履歴の書き換え・強制pushは行いません。本人用Privateのmainを再読み取りし、対象ファイルと一覧の行がなくなったことを確認して、実際のコミットを報告します。

今後の照合・ふりかえり・バックアップ復元で、取り下げた記録を再登録しないようにします。必要な管理メモには対象の識別と利用停止の状態だけを残し、削除した本文をコピーしません。AIに渡さない管理情報は接続の外で保管します。

「既存の行は消さない」「原記録を保持する」は、本人の利用停止・削除の意思の例外です。詳しくは[本人と決める手順](../../docs/record-choices.md)を参照してください。
