# 例09: 残したくない記録を取り下げる（架空）

- 作成日: 2026-10-02
- 更新日: 2026-10-02

[例06](06-one-line.md)で保存した記録の取り下げです。

## 送る一言

```text
10月16日の月の記録を、本人が「のこしたくない」と言っています。使うのを止めて、削除したいです。
```

## 最初に返す内容の例

> この記録を、以後の要約や提案には使いません。記録本文、index.md、questions.md、派生文書にある関連箇所を確認し、削除の対象をまとめます。内容そのものは返答に引用し直しません。

## 対象を確認したあとの案

| 確認先 | この例で確認できた状態 | 行うこと |
| --- | --- | --- |
| 原記録 | `experiences/261016-moon.md` がある | mainの現在のファイルを削除 |
| index.md | 対応する題名・リンクの行がある | 行を削除 |
| questions.md・派生文書・添付 | この例では関連箇所なし | 変更なし |
| Git履歴 | 過去のコミットに残る | 今回は書き換えない。現在のファイルの削除とは区別 |
| 保護者の端末・バックアップ・AIの会話 | AIからは確認できない | 保護者が確認し、必要な削除を行う |

> 今回は、mainの現在の記録ファイルとindex.mdの対応行を削除する範囲で進めてよいですか。Git履歴や手元のコピーには残るため、完全な削除とはなりません。

## 保護者が範囲を指定する

```text
本人と確認しました。今回は現在のファイルとindex.mdの行を削除してください。Git履歴は変更しません。手元のコピーとAIの会話は私が確認します。
```

指定の範囲を削除し、mainを読み直して結果とコミットを報告します。

取り下げた記録は再登録しません。管理メモには識別と利用停止の状態だけを残します。

詳しくは[本人と決める手順](../../docs/record-choices.md)を参照してください。
