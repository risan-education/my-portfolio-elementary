# わたしの「なんで？」ノート

- 作成日: 2026-09-25
- 更新日: 2026-10-01

## 小学生の My ポートフォリオ

**保護者がChatGPTに話しかけて、子どもの体験・「なんで？」・作品・考えの変化を、本人の言葉のまま残す教材です。** 「なんでだろう」「やってみたい」「うまくいかなかった」を一言から。ChatGPTが用紙に整え、保護者と子どもが内容を確かめて、保護者が管理する **Private（非公開）GitHubリポジトリ** に保存します。絵でも、一言でも、おとなに話した言葉でも大丈夫。毎日書く必要も、すべての欄を埋める必要もありません。

**子どもは体験とことばの主役。ChatGPTへの入力とGitHubへの保存は保護者が担当します。** 入試の実績づくりを急がず、そのときの興味を大切にします。

版: **0.2.0** ／ [はじめ方（ChatGPTの登録・設定から保存まで）](docs/getting-started.md) ／ [AIに整理を頼むとき](docs/ai-guide.md) ／ [なぜ小学生のうちから記録するのか](docs/why-portfolio.md)

### 5分で始める

1. [ChatGPT](https://chatgpt.com/)を開き、保護者のアカウントでログインします。登録や有料プランの選び方は[はじめ方](docs/getting-started.md)にあります。
2. 子どもの一言と活動日を、メモのまま送ります。例: 「10月3日、公園でダンゴムシを集めて『なんで丸くなるの？』と言った。」 決まり文句は要りません。用紙選び、本人の言葉をそのまま残すこと、日付の扱いは、ChatGPTが指示書（AGENTS.md）に従って行います。
3. ChatGPTは文章案といっしょに、「課題の設定」「情報の収集」「整理・分析」「まとめ・表現」の順で足せそうなことを1つずつ聞きます（合計4問まで）。答えられるものだけ答えます。返ってきた本文を子どもと読み直し、保護者用の非公開フォルダまたはPrivateリポジトリの `experiences/YYMMDD-dangomushi.md` などへ保存して開き直します。**チャットに文章が表示されただけでは、保存完了ではありません。**

ChatGPTを保護者のGitHubに接続すると、読み取りから保存まで会話の中で頼めます。接続の手順は[はじめ方](docs/getting-started.md)、環境によって使えない機能は[確認状況](docs/connection-check.md)を確認し、最初は架空の記録で練習してください。用紙は無料です。AIサービスの費用は別です。写真・動画の原本は保護者の外部ストレージに保管できます。

### 保存先を用意する（初回だけ）

1. [はじめ方（保護者向け）](docs/getting-started.md)に沿って、ChatGPTの登録・プランの選択・アプリのインストールを進めます。
2. 保護者用のGitHubアカウントを作り、ChatGPTに聞きながら接続の設定と、このテンプレートの **Private（非公開）** での複製を進めます。
3. ChatGPTに「やったこと」「子どものことば」を伝え、用紙に沿ってファイルを作るよう頼みます。作成日・更新日もChatGPTが記入します。
4. 内容を子どもと見直し、GitHubに反映します。続きが気になったら、ChatGPTと相談して[探究ノート](templates/inquiry.md)へ進みます。

### 子どもといっしょに

> なにを見つけた？
>
> どこがふしぎだった？
>
> つぎは、なにをためしてみたい？

答えが出なくても、途中でやめても大丈夫。「わからない」も大切な記録です。

### なぜ小学生のうちからMyポートフォリオを作るのか

主に「探究学習メモ」として使います。目的は次の四つです。

1. **探究学習に慣れるための練習。** 小学校の学習指導要領は「課題の設定→情報の収集→整理・分析→まとめ・表現」を繰り返す探究的な学習を重視しています。家庭の「なんで？」を一言残し、「つぎは何をためす？」と考えることが、その入口になります。
2. **自分がやりたいことを探す練習。** 何に夢中になり、何を途中でやめ、何をまた始めたかを本人の言葉で残すと、あとで本人が「好き」「得意」「苦手」を見つける材料になります。大人やAIが性格や適性を決めつける材料にはしません。
3. **将来の推薦入試や就職活動にも役立つ。** 大学の総合型選抜・学校推薦型選抜や就職活動では、本人が書く活動報告書・志望理由・面接で「なぜ始めたのか」「どう考えたのか」を問われます。小学生の記録がそのまま提出物になるわけではありませんが、自分の言葉で経験を説明する練習と、中学・高校の探究の出発点になります。
4. **AIを使うときのコンテキストとしても役立つ。** 本人が確認した記録は、ChatGPTなどに自分の背景を伝える「外部記憶」になります。原記録を変えず、渡す範囲は本人が選びます。

小学生のうちは残すだけで十分です。ためた記録は、中学・高校の探究学習の出発点、大学入試の活動報告書や面接の材料、大学生の就職活動での自己分析、社会人になってからAIに自分の背景を伝えるコンテキストとして、原記録を変えずに使えます。詳しくは[将来の使いみち](docs/future-use.md)を参照してください。

### 記録を続けるメリット（公的資料と研究から3点）

**1. 振り返る習慣が「学びに向かう力」を育てる。** 文部科学省は2020年度から全小中高で「キャリア・パスポート」（児童生徒が活動を記録し蓄積するポートフォリオ）を実施し、その目的を「自らの学習状況やキャリア形成を見通したり、振り返ったりして、自己評価を行うとともに、主体的に学びに向かう力を育み、自己実現につなぐもの」としています。小学校学習指導要領解説も、探究のプロセスを意識して学ぶ児童ほど各教科の正答率が高い傾向を示しています。小学生を対象にした49研究のメタ分析でも、計画・見直し・自己評価を教える指導は平均効果量0.69で、小学校段階から有効でした。

**2. 消えてしまう「そのときの言葉と気持ち」を、自己理解の材料として残せる。** 学習指導要領解説は、体験したときの感覚や思いは時間とともに薄れるため、言語化して蓄積するよう求めています。キャリア・パスポートも、教科だけでなく家庭や習い事など学校外の活動を含め、小学校から高校卒業まで持ち上がることを前提にし、大人が対話的に関わることで自己有用感や自己変容の自覚につなげるとしています。国立教育政策研究所は、小6の記録を中1で読み返し、時間を越えて自分の成長を自覚する実践を紹介しています。本教材が本人の言葉を書き換えず、原記録を保持するのはこのためです。

**3. 将来、自分の言葉で経験を説明する材料になる。** 令和8年度大学入学者選抜実施要項は、総合型選抜で「入学志願者本人の記載する資料」（活動報告書、大学入学希望理由書、学修計画書等）を積極的に活用するとしています。活動報告書に書くのは高校までの学習・活動の履歴なので、小学生の記録が提出物になるわけではありません。一方、文部科学省のQ&Aは、キャリア・パスポートを入試にそのまま使うことは適切でないとしつつ、本人が面接や自己申告書に取り組む際の「情報の一つとして参考とすることは考えられます」としています。OECDのラーニング・コンパス2030も、行動のあとの振り返りが自分の将来の行動に対する見通しと力の感覚、つまりエージェンシーにつながるとしています。本人が確認した記録は、AIに背景を伝えるコンテキストとしても根拠付きで使えます。

出典と引用箇所は[なぜ小学生のうちから記録するのか](docs/why-portfolio.md)にまとめました（確認日: 2026-09-27）。入試や就職の結果を保証する教材ではなく、本人の意思に反する記録を強いません。

### 保存する場所

| 場所 | 内容 |
| --- | --- |
| `profile/` | 好きなこと・興味（任意） |
| `experiences/` | 日々の体験・読書・疑問 |
| `projects/` | 続けて調べる探究・作品 |
| `reflections/` | ときどきのふりかえり |
| `annual-review/` | 年間ふりかえり |
| `questions.md` | 本人の問いを日付付きでためる台帳 |
| `derived/` | 記録から作る要約・報告書の下書き（原記録は変えない） |
| `assets/` | 写真・PDFの控えや所在メモ |
| `templates/` | コピーして使う空欄の用紙 |
| `examples/` | **すべて架空**の記入例。本人の実績に含めません |
