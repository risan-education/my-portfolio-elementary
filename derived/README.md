# 派生文書（記録から作る二次文書）

- 作成日: 2026-09-26
- 更新日: 2026-09-26

`experiences/` `projects/` `reflections/` などの**原記録**をもとに、あとから作る文書を置く場所です。原記録そのものは変えません。

| 例 | いつ使う |
| --- | --- |
| 根拠付きの要約 | 数か月〜数年分の記録から、続いている興味や変化をまとめる |
| 活動報告書・志望理由書の下書き | 中高の探究発表、総合型選抜・学校推薦型選抜の書類 |
| ガクチカの材料メモ | 大学生の就職活動で「なぜ始め、何に困り、どう考えたか」を整理する |
| AIに渡す自己紹介（コンテキスト） | 新しいAIの会話で、自分の背景を短く伝える |

用紙は [根拠付き要約](../templates/evidence-summary.md) を使います。将来の使い方は [将来の使いみち](../docs/future-use.md) を参照してください。

## ルール

- 派生文書の各段落に、根拠となる原記録へのリンクを付ける。根拠のない主張は書かず、「根拠なし」「判断できない」と書く。
- 本人の言葉は原記録の表現のまま引用し、大人向けの言い回しに置き換えない。要約は要約と明記する。
- 冒頭に「作成日・更新日」「目的（誰に、何のために）」「対象期間」「使ったAI（使った場合）」を書く。
- 派生文書を作っても、原記録は書き換えない。原記録の誤りに気づいたら、原記録側に日付付きで訂正を追記する。
- 派生文書は本人と一緒に見直す。本人が使いたくない記録は入れない。
- ファイル名は `YYYY-MM-DD-purpose.md`（例: `2032-06-01-activity-report.md`）。同じ目的で作り直したら新しい日付で別ファイルにし、古い版は残す。

実記録は自分用のPrivateリポジトリにのみ追加してください。配布元にはこの説明だけを置いています。
